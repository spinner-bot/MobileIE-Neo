# 第一轮探索协议：评价校验、传统控制与组合筛选

- 创建：2026-11-10 18:07 +08:00 · Codex  (sqs_A100)
- 触发：用户授权自主开展调研与预实验，以多种候选及其组合寻找有效研究切入点。
- 阶段：前期探索，不作为正式论文实验或最终路线选择。
- 实验身份：`exploration-r1-v1`；不修改或覆盖既有3/4号工作结果。

## 问题

1. 修正平移有效区域与光流方向后，旧指标偏差有多大？
2. 单帧传统去噪、输出平滑、运动补偿、增强映射稳定各自有效吗？
3. 输入去噪与运动补偿是否互补？低光运动估计是否是组合的瓶颈？
4. FST/注意力的扰动响应能否提供后续结构研究的依据？

## 数据与预算

- 使用仓库现有 `source_scene.jpg` 和 `MobileIE/datasets/lle/gt/{1,22}.png`，按文件内容哈希记录来源。
- 这些素材包含既有基准图片，只用于可解释预实验；不据此声称独立测试泛化。
- 主筛选：3场景、每段32帧、320×240；平移速度0/4/12像素每帧；退化噪声种子0/1。
- 每张图统一缩放为1024×768再裁剪，位移不超过有效区域。人工缩放与纯平移是本轮局限。
- 低光退化沿用 `(x/255)^2.2*0.35`，泊松40光子、读出噪声0.008、可选JPEG70；方法共享完全相同的输入序列。
- 主要条件为噪声+JPEG；另用确定性低光序列诊断clean残差。
- 使用官方 LOLv1 slim 权重；本轮不训练、不调整模型权重。
- 首选单张空闲GPU0；执行前复查，最多占用同一组4张空闲卡。本轮实际只需1卡。
- 无墙钟截断，以明确的场景、帧数、种子和方法矩阵结束。

## 方法矩阵

- 原模型逐帧推理。
- 同一段输入下冻结首帧全局注意力（机制干预）。
- 输入双边滤波后增强（传统单帧去噪控制）。
- 输出空间平滑（区分残差改善和细节模糊）。
- 输出EMA，alpha=0.7/0.9。
- 低光输入估计反向Farneback光流的运动补偿EMA，alpha=0.7/0.9。
- 真值平移补偿EMA，alpha=0.7/0.9，作为运动估计分析参照，不作为可部署方法。
- 输入双边滤波+在滤波输入上估计光流+输出运动补偿EMA（组合）。

先固定参数完成一轮，避免在测试图片上挑最优配置后声称普遍有效。后续参数扫描另建实验身份。

## 评价与必要检查

- 平移比较：`prev[:, pan:]` 与 `cur[:, :width-pan]`；无回卷，使用浮点减法。
- 反向warp：当前像素到上一帧的对应坐标；越界使用有效mask，滤波越界位置回退当前输出。
- 单元校验包括零运动、已知平移、无效边界、浮点/uint8差分、光流方向和PSNR。
- PSNR统一为整幅RGB MSE再取对数，输出clamp范围统一；另报告有效区域的运动对齐帧差、相对GT帧差误差、边缘误差。
- 同时计算旧版对齐残差，直接量化评价修正的影响；旧值不与新值混合排名。
- 补充去除四边8像素的内部区域残差，以区分卷积padding边界效应与内部不一致；所有方法共享该区域。
- 记录方法耗时，但本轮Python/CPU光流与GPU混合的耗时仅为工程诊断，不能当作正式延迟基准。
- 所有统计以序列为单位；不把相邻帧当作独立实验样本。
- 保存逐序列CSV/JSON、配置、素材/权重哈希、软件环境、命令、stdout、图和分析。

## 后续决策

补充机制探针（执行前登记，身份 `exploration-r1-feature-noise-v1`）：在同样3个固定场景上，用20/40/80光子与有/无JPEG两种条件，每组16次独立噪声采样；记录FST前后、全局/局部注意力和输出层相对clean特征的扰动、偏差及随机方差。JPEG开关复用同一批噪声。保存FST线性项、二阶项、交叉项与真实变化的恒等式误差；这些统计不被解释为各层的因果贡献比例。

- 去噪控制有效：补充传统强去噪和学习型去噪，进一步区分降噪与增强映射稳定。
- 真值补偿明显优于低光光流：优先研究可靠性/运动估计/特征对齐，而不是加大固定平滑。
- 冻结全局注意力效果有限：不能直接排除注意力作用，后续使用匹配画质与重训控制。
- 组合有效但运动细节退化：探索置信度状态更新、曝光控制与细节分流；所有方向先核查相关工作。
- 本轮结束后记录正结果、负结果、无法回答的问题及下一轮的具体假设，保持多路线开放。
