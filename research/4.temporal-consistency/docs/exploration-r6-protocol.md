# R6：条件噪声矩、二阶项与RGB去偏的可识别性

创建：2026-11-11T16:43:44.638388+08:00；作者：Codex  (sqs_A100)；原因：0015未建立低分辨率历史的独立贡献，转向根部算子的机制诊断，避免继续加模块。

## 问题与已知代数

对固定场景、固定位置，u=mu+e且E[e]=0，FST=a*u²+b。无须高斯假设：

```text
E[FST(u)] - FST(E[u]) = a*m2
Var(FST(u)) = a² * (4*mu²*m2 + 4*mu*m3 + m4-m2²)
mj = E[e^j]
```

分别记线性项L=4mu²m2、二阶能量Q=m4−m2²、协方差项C=4mu*m3。C可以为负，Q/总量可超过1，不能把三项当非负独立贡献。对有限样本用按draw的经验均值和population矩（除N）时，该恒等式也精确成立。均值去偏减去常量a*m2，**不会改变该层的条件方差**；下游非线性仍可能改变RGB波动。

这些是基础恒等式，不是创新。FC-AIDE已有二次像素映射与无偏风险估计；其独立、对称噪声/上下文隔离条件不自动适用于MobileIE非线性特征或JPEG。重复噪声的偏差—方差分析也有先例。

## 固定输入与模型

使用现有Kodak探索验证07–12六图，沿R3固定128×128区域[192:320,320:448]，不触碰保留13–24。photons20/80×JPEG关/开(q70)，read sigma=.008，沿现有degrade，24种静态输入条件。

每条件独立生成校准64次和评价64次，两个seed区间分离；各模型共享完全相同字节输入。共3072个独立随机退化图像（不是3072个视频）；不增加新实拍来源。所有像素缓存仅本地，提交hash/配置/汇总。

固定三组权重：官方原模型、R5 plain seed0 step1000、R5c spatial_post seed0 step1000。代表性机制比较，不对训练种子做普适结论。校准仅估计每位置head/body卷积后、平方前的mu和variance。评价样本独立于校准；经验矩恒等式审计单独用评价样本自身的中心矩。

## 有限干预

每条件/模型评价五种冻结控制：原样、仅head减a*校准variance、仅body减a*校准variance、仅head减a*(u−校准mu)²、仅body减a*(u−校准mu)²。后两种相当于在校准mu附近线性化该次平方算子；只改一层以避免上游干预改变下游统计的混淆。

每次记录clamp前/后的RGB MSE、条件均值bias²、输出variance、MSE分解闭合误差、平均逐draw PSNR及亮度偏差，剔除8像素边缘。记录每通道L/Q/C、总量与直接方差、Jensen偏移及实际校准均值与无噪声输入特征差异。跨层绝对能量不能直接比大小。报告按场景/噪声/JPEG分层的比值和有限样本敏感性，不将二阶项存在当作闪烁主因。

另列model(mean评价input)、mean评价output及model(无量化无噪声low)的PSNR作为不可部署参考。它们使用多次同景观测或知道无噪声，不得与单帧可部署方法混排，不能称零成本去闪烁。

## 判断规则与资源

若Q相对L+C很小，或理想去偏主要改变均值却不能改善RGB方差/质量，则降低“仅补偿平方偏置”的优先级；若有稳定窗口，再考虑可估计噪声/低成本替代。即使oracle有效，也不能推出可部署估计已解决。
