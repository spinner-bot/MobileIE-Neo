# R31：真实手机视频的固定外部开发资料

登记：2026-11-12 03:28 +08:00；作者：Codex  (sqs_A100)。当前已读取官方归档目录，手机视频/图像尚未解码；R28训练仍等待共享GPU。该轮先完成数据获取与解码，不增加模型训练或参数网格。

来源为[LLIV-Phone作者仓库固定版本](https://github.com/Li-Chongyi/Lighting-the-Darkness-in-the-Deep-Learning-Era-Open/tree/106e914a5fa5842cca454eb0a48076e8b274f85f)公开链接的`LoLi-Phone_release.zip`，原始视频与预处理JPEG都在归档中。实际目录见[元数据](../process/external-phone/archive-metadata.json)：3673043597字节、120原始视频、45092个JPEG成员；README写45148图像，两种计数不混同。预处理JPEG不能替代原视频采样时间/方向证据，因此本轮取原视频。

为覆盖不同品牌/ISP，在元数据中固定Huawei Mate 20 Pro、Pixel 3、iPhone 11，各取该设备原始视频路径字典序第一项，不按观感或指标替换：

|设备|原始文件|ZIP解压字节|
|---|---|---:|
|Huawei Mate 20 Pro|VID_20210209_183437.mp4|10162099|
|Pixel 3|VID_20210213_223036.mp4|30514807|
|iPhone 11|IMG_1541.MOV|9556797|

只获取上述三个原始成员，核对ZIP CRC/大小并保留SHA256；资产全部落在自有`.cache/datasets/LLIV-Phone/pilot`。不执行归档自带脚本。用自有OpenCV视频后端顺序解码各前64帧，记录容器报告FPS/帧数、实际解码时间戳、显示方向处理与原分辨率；保存RGB及时间戳。显示方向按后端实际行为记录，不把不可取得的元数据编造为已知。长边缩至640、另一边四舍五入到最近偶数，INTER_AREA，不裁剪、不额外加噪/改变亮度。若视频不足64帧或解码不支持，保留失败，不换片。若时间戳无效，标注限制，不把平均FPS当作精确采样时刻。

本项目未获得与这三段同步的正常曝光参考；不计算伪有参考PSNR/SSIM，也不把更平滑、更暗或丢失运动当成增强成功。后续只用既有固定终点模型/经典post参考作共同输入检查及并排展示，单帧和带历史推理分开；无参考时序变化代理、曝光/截断/细节统计及观感联合检查，不能由单一flicker数值排名。手机输入来源不等于手机端延迟实测，后者仍缺。

这三段是新的外部开发资料，不是完整LLIV-Phone基准、最终测试或用户研究。其余视频不解码，正式外部有效性仍需完整独立协议。优先完成R28固定终点和强参考，R30/R31提供可访问的外部验证入口，不扩大候选算子搜索。
