# R51｜有限二次相位积分原型，仅CPU机制阶段

事前登记：2026-11-12T19:12:35.514214+08:00；作者：Codex  (sqs_A100)。只检验一个可利用原FST结构的有限改写，非新颖性声明；不用R47部分结果挑模型、无GPU训练/新DEV或最终数据。

1. CPU FP64原型验证：Q=Σ(m/d二维核作用u)²与周期pad→双线性2×align_corners=False→平方→2×均值直接路径输出/反向最大差≤1e−10。随机奇数非方形、常数及Jensen上下界；失败保留不放宽门槛。
2. 已知周期解析格栅63²，频率(5,0)/(19,0)/(19,13)，16分数相位δ=(t/16,t/32)。比较square、Q、preblur、postblur与FFT2×理想square oracle。频率超原Nyquist后的误差是机制阳性控制；FFT oracle分数平移RMS≤1e−10、整数控制≤1e−10。Q不能冒称达到该oracle或理论零误差，不以格栅通过直接进入训练。
3. 从既有MixedPool只取seed50/step0四个GT首帧，左上127²（奇数避免Nyquist歧义）；2SYN/2real已有训练资料。用GT^2.2×.35构造无新增噪声输入，DFT box低通|f|<.45周期信号。各crop全部16相位及整数控制共同用一次固定仿射缩放到[.01,.35]，不逐帧重新归一化。记录来源与缩放。是人工无噪周期代理，不能报真实视频/原退化PSNR或独立泛化。
4. 固定R44 square_mse8000两个seed部署权重（R50不采用），其卷积都改circular以隔离边界；两FST均分别替换为raw/Q/preblur/postblur共四模式，其余参数原样，4075，0优化。仅16相位/8个seed×crop×4模式=32序列512CNN，另整数校验及相位0按已有输出复用。crop/seed不挑选，no clips与clip两路径均记录。整数周期原理误差≤2e−5归一化RGB。
5. 主要机制量为F(Tδx)−TδF(x)的非零15相位平均MSE（unclipped/clipped分开）及phase0相对同权重raw映射的MSE扰动，均不是GT质量。Q后续资格：每seed四crop平均unclipped相位MSE≤raw的.8且≤两个匹配平滑中更优者的.9；每seed至少3/4crop不差于raw；phase0映射扰动不超过两个平滑控制更小者的1.05倍（只对非raw比较）。所有条件满足才另登记真实padding/画质控制的后续，不直接训练/称新方法；clip仅完整报告不替代主门槛。

失败则停止这一有限2×双线性/面积Q的kernel/强度/相位/追加seed网格，不据此否定全部抗混叠或继续FFT/滤波大搜索。即使通过，已知先例强，创新仍需具体新贡献与质量—时序—成本事实，独立最终素材不打开。代码、原型/结果、过程/决策/报告分别小步提交，完整阶段推送；所有资产自有zrh data，R47活跃核心不改。
