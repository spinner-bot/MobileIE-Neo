# R83固定训练窗状态算子前置检验

2026-11-17；Codex  (sqs_A100)。登记先于新窗口/冻结F0前向/对应计算。R82与全部旧STOP保持；此为一次CPU信息范围/目标条件检验，不是新模型、性能评价、扩大匹配器或H核网格。依据[note67](../../5.prior-art-survey/docs/67-distillation-targets-and-state-operator-support.md)与[R28监督勘误](training-target-provenance-r83.md)。

固定四个原MixedPool训练窗口：(data seed0,step8000/8001)、(data seed1,step8000/8001)，原B4T4×128、每窗2 SYN/2 real。两个既有R44 square_mse最终F0都在相同四窗eval/冻结CPU计算，合32次B4骨干前向/128图块。GT相邻48对的原half-FB场只计算一次；两F0各48对的场各自计算，共144 half-FB对/288 Farneback估计。原loader预载训练缓存，不把128入网裁块冒充仅解码128块。没有新DEV/最终像素、SGD/H前向或GPU。

固定当前c、由前/当前raw估计的flow及FB/bounds接纳，原strong-rec的线性状态项为A=.5*valid*B_flow。采用cv2.convertMaps读取INTER_LINEAR的原1/32量化权重及BORDER_REPLICATE坐标，四邻权重按实际重复坐标合并计算能量，不用连续浮点插值冒充原算子。拒绝区域A=0、当前帧fallback单独保留。

仅在一个16×19人工字段资格里核解析apply与原align_history+blend(.5)的差≤1e-6、row sum=.5*valid、同算子距离0、局部/非局部能量相加。固定两组位移(3.25,−1.5)、(−2.25,1.125)及固定拒绝mask；不扩位移/核/精度网格。16个固定三通道Rademacher探针仅核归一算子距离的采样解释，解析量为主，不以随机误差追种子或作性能。资格失败保留并停，不放宽容差。

真实窗每个非首帧记录：GT-derived及F0-derived接纳率/重叠率；F0算子总系数能量、历史半径2之外的系数能量/比例；两种算子在共同接纳域的对称归一差`||Aobs−Agt||F²/(||Aobs||F²+||Agt||F²)`，另报全域以分离mask变化。相同输出行的相同源坐标才能计算交叉项。零分母记0且资格不通过，不剔除难窗/边界或改ROI。

域分SYN/real、模型seed0/1，按原8个对应窗样本/域的原相邻对累积能量后取比，不把两模型/4窗口当独立视频基准。H1资格要求四个域-seed的F0接纳覆盖率≥.25且支持外能量比例≥.20。H2要求共同接纳覆盖率≥.25且共同域归一算子差≥.10，四个域-seed均满足。阈值是是否值得下一核心原型的必要前置信号，不是统计显著性或新方法门槛。

只有H1/H2同时满足，才允许进入另行定义的、与旧配置有明确不同信息路径/学习机制的核心原型设计；不自动开正式训练。任何必要组失败，本观测/目标动机不足，停止此随机状态算子路线，不换窗口、位移半径、阈值、teacher或随机draw挽救。即使通过，也不证明真实视频不可约误差、GT场错误、R74/R82失败因果或新颖性；不修改旧网络/预算/STOP，不以此解封旧teacher/核网格。
