# R46｜固定坐标历史的独立合成机制门槛

## 问题与算法

能否通过改变历史状态坐标而非门控容量，减少强递归的插值保真损失？已知运动、无遮挡的控制排除流估计误差，不代表自然视频。普通因果递归为z[t]=(1−α)y[t]+α W(z[t−1],−v)。

候选固定K=8：锚时刻a的状态h不逐帧搬动；当前输出z[t]=(1−α)y[t]+α W(h,−(t−a)v)。如t−a=8，则h=z[t],a=t；否则将新观测一次对齐锚坐标，h=(1−α)W(y[t],+(t−a)v)+αh。越界输出回退当前，锚内新观测无效处保留旧h；不复用渲染后的输出作为下一状态（重置时除外）。K=1必须还原普通递归。固定双线性/OpenCV remap、float32、不锐化、不重训。

真实运动版本若开展，还须组合双向位移并传递有效性；半分辨率4通道位移约1个全分辨率通道，状态预计7通道对原6通道，增加约16.7%历史内存，并有第二RGB warp及流组合。当前oracle平移无需该图，不能用它声称零开销、手机实时或可折叠单帧。

## 固定资料和预算

仅CPU、OpenCV两线程、零GPU/零CNN/零真实或DEV像素。解析RGB纹理192×224×32帧；值0.5加三个正弦，幅值.10/.08/.06，频率(x,y)为(.08,.05),(.23,−.16),(.37,.10)，每分量RGB相位channel×(.4,.7,1.1)。GT[t](x,y)=s(x−v[x]t,y−v[y]t)，每帧直接解析生成，不以采样产生GT。

运动固定三种(0,0)、(1,0)、(.375,.25)。噪声σ0/.03，独立浮点高斯且不clip/量化；clean只seed0，noisy四seed0–3。所有方法同输入。五个沿用alpha .1/.25/.5/.75/.9，普通递归与候选K8，合计30clean+120noisy=150输出序列。首帧原观测。无K、频率、噪声、seed或alpha追加搜索，无参数更新。

## 门槛和止损

先核验K1普通递归差≤1e−6（全部帧，含边界）；零/整数平移中央ROI固定margin48、K8对普通差≤1e−5，排除坐标方向/边界泄漏。已知运动真实对齐需保留解析oracle约定。不以噪声下降代替保真。

主要门槛只用预设分数运动、α=.75、晚16帧中央ROI：clean的MSE比candidate/classical <.95，且四noisy seed的均值MSE比<.95。二者均过才考虑真实流/实际增强检验；失败就冻结本K8双线性坐标状态，不再调K/插值/频率追分。记录全部150行MSE/PSNR、逐帧MSE及输入raw参考；MSE=0时PSNR记null。时间GT-change残差与谱恢复可后续单独登记，当前不追加未登记胜出指标。

实现错误可以保留失败后更正并记录重跑，不改变门槛；先过坐标不变量才接受质量结果。无自动重试。耗时只是合成脚本时间，不作流水线成本。即使过门槛也只是已知理想运动的机制信号，不是新颖性、真实增强胜出或论文方法。代码/结果/过程/报告分文件提交，阶段推送，所有运行资产在自有data。
