# R32：公共动态训练资料池登记

记录：2026-11-12 04:31 +08:00；作者：Codex  (sqs_A100)。R28路线冻结后，先准备真实动态来源的共同训练资料，再另行登记少数骨干对照。本协议仅授权数据取得与完整性记录，不启动训练，不预先确定新方法或声称创新。

采用R30相同[DAVIS官方480p TrainVal归档](https://davischallenge.org/davis2017/code.html)，沿用已保存的官方TRAIN60/VAL30文本及ETag。训练资料池严格为TRAIN减去已经作为外部开发片使用的bear、lucia、walking，共57个视频ID。三个开发片不进入新训练；VAL以及其它既有最终保留图像不读取。此为按视频ID划分，不声称已经检查所有语义/背景相似性。

每段按原文件名排序取前min(64,可用帧数)张连续480p JPEG，至少应有2帧；不因内容、噪声或未来质量换片。先保存57段及全部选中ZIP成员的元数据清单，再获取图像。短序列保留原帧数，不通过复制补足64帧，也不根据观感选择另一段。具体总帧数、大小、CRC由元数据实测后记录，不能写成预先假定的3648帧。

只下载登记的TRAIN成员，不整体解压TrainVal。最多4并发Range，核对归档ETag、成员CRC/大小并记录每文件SHA256。运行资产位于 `/data/Users/zrh/data/MobileIE-Neo/cache/datasets/DAVIS2017-train-rest`；代码、划分/来源清单、成功或失败日志分别提交，完整完成后阶段推送。数据可重试网络读取，但已存在内容须CRC/大小一致，不覆盖不匹配文件；不自动启动部分资料上的训练。

本阶段不定义模型、优化器、步数、退化参数或最终验证协议。后续全部比较必须共享此资料池及相同训练预算，以独立空间控制区分容量、训练改变和实际历史收益；取数不等于新实验方法。新训练另行注册，R30三开发片只作开发反馈，正式未读测试仍需保留。来源是普通公开视频，合成低光不变成真实低照度传感器采集数据。
