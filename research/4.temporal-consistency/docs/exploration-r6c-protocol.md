# R6c：从局部方差到RGB方差的精确分解

创建：2026-11-11T16:56:45.835055+08:00；作者：Codex  (sqs_A100)；原因：R6b保持均值的理想head干预提升PSNR却未统一降低RGB波动，不能用未加权特征二阶能量推断输出闪烁原因。

这是一项针对已见R6/R6b结果的适应性机制诊断。复用相同24静态条件、三组权重与每条件64评价draw；不使用新素材、不训练、不假装独立确认。

## 精确代数

记body平方前 u=mu+e，采用评价draw经验均值及population矩。FST输出f=M+L+Q，其中 M=a*(mu²+m2)+b，L=2a*mu*e，Q=a*(e²−m2)。对于spatial_post，修正是线性算子T，将M/L/Q分别过T，三者仍相加。

实际门控W_t为channel-attention×spatial-attention，Wbar为draw经验均值，dW=W_t−Wbar。tail为线性卷积K加bias：

```text
y_t = K(Wbar*M)+bias
    + K(Wbar*L_t) + K(Wbar*Q_t)
    + K(dW_t*M) + K(dW_t*(L_t+Q_t))
```

计算四个RGB分量，分别为平均门控下线性/二阶特征项、特征均值上的门控变化、门控—特征交互。每项再按draw减均值，得到协方差矩阵；总方差是所有矩阵项之和。各项相关，协方差可负；Cov(分量,总输出)/Var(总输出)是代数归属量，可负且不代表移除该项的因果收益。

实际FP32表达式与FP64分解的差另列rounding_residual，要求其中心方差/原RGB方差≤1e-4，否则视为实现需排查，不能靠残差强行掩盖错误。clamp后额外加入clip(y)−y的中心分量，保留clip非线性影响。

## 固定预算与核验

24×3×clamp前后=144条协方差记录。所有空间指标剔除8像素边缘。核验raw重复与R6相同，协方差闭合，以及CPU FP64小张量中分量和原前向等价。原始FST局部Q能量与RGB分量能量/协方差并列，不能跨层直接比较绝对特征数值。

仅解释body最后一次平方及后续门控，head的非线性影响已经包含在body u内，不将“body的线性特征项”误称整个网络对输入线性。无高斯/局部线性近似假设，无新可部署算法或速度收益声明。
