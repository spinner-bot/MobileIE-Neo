# R73｜原生双矩进入第一次平方的固定机制检验

登记：2026-11-13；作者：Codex  (sqs_A100)。R72全部原链已正常结束。本轮只检验一个组合机制，不再扩展参考家族；基础组件有明确先例，尚无独立新颖性或方法成功。

## 问题及与旧工作的差别

保留R44 square_mse累计8000的原完整expanded MBR/12通道dense空间骨干，改变第一次FST的信息处理。R64历史为池化/投影后放大加性校正；本轮不改其宽度/尺度网格，而是在原生特征上递归维护一阶与二阶非中心矩，并在平方读出时显式选择是否保留离散度。R37的冻结骨干条件也不沿用。空间骨干、匹配器和新参数均共同训练，无额外时间loss或GT运动/历史输入。

设当前head.block1输出z，过去状态(m,s)。低分辨率预测器只读取avg_pool4(z)与avg_pool4(m)，24通道depthwise3×3→pointwise8→PReLU→pointwise3，最后层零初始化，产生原生±8像素偏移与sigmoid历史权重g（初始.5）。原生双线性同坐标传输m及s；越界g=0、回退当前。更新m'=(1−g)z+gWm、s'=(1−g)z²+gWs，v'=max(s'−m'²,0)。第一次FST输出为a·(m'²+rho·v')+b，a沿原weight1/weight2乘法次序，rho为12个零初始化可学习系数，不限制符号。状态是经验混合矩，含运动/纹理/插值差异，**不是已标定传感器噪声或精确贝叶斯方差**。

无历史时使用(z,z²)作为过去；有权重的current替换也始终用当前(z,z²)，保留本模型自身空间处理。首帧必须等于自身current，不要求训练后的首帧等于旧骨干。field初始偏移零，所以初始current=原映射；实际历史初始允许改变输出，不伪称函数保持。矩与mean控制初始因rho=0而一致。所有FST后续原body/HDPA/tail保持。

rho=0是平方均值，rho=1等于混合平方响应；基本恒等式及一般双线性/矩融合均不能单独称创新。EMVD、ABM、FilterFusion和NCFL先例见note47/53；本项目是否有可辩护的具体系统差异仍待结果与后续最近方法核查。本轮可证伪问题是：这种显式离散度是否在共同训练后，比完全相同原生均值状态带来独立、稳健收益。它不是R61零历史一阶响应二次差分族，历史通过m直接进入一阶响应；不回写任何旧失败。

## 三个固定控制与预算

- spatial：相同双矩模块/参数，但每帧把过去替换为当前；可学习局部空间采样，没有真实过去。
- mean：真实过去一阶矩，同一匹配器/骨干，rho固定0且不保存二阶状态；少12参数，差异明确报告，不假装完全同容量。
- moment：真实过去双矩与可学习rho。部署参数预期spatial/moment4562、mean4550，含保留原4075；实际以导出核验为准。

三者从同seed相同R44最终expanded8000初始化，field随机数独立于空间初始化，三个模型/Adam无共享。两seed各三模型新4000，共24000正式更新；MixedPool固定step8000..11999、batch4/T4/128crop，原同50/50真实/合成、raw clipped MSE全帧、Adam1e-4/(.9,.999)/eps1e-8/wd0、global clip1、四次BN调用、不在clip内detach。每1000只备份，唯一new4000最终选模；无墙钟截止/科学自动重试，不扩loss/LR/长度/rho初始化/尺度/宽度/seed网格。

旧R64 plain相同数据范围/训练预算的最终12000可直接作为匹配继续适配参考，另保留R44原8000和各自强rec，不重新训练plain或跑逐tensor/Adam回放。三新控制均保留累计8000+4000及不同公开起点限制。新训练依赖/完整后续链提交冻结后才GPU准入。
