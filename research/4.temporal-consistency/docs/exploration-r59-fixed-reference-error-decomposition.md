# R59后续解释：固定参考的有限样本误差分解

创建：2026-11-12T23:04:33.756433+08:00；作者：Codex  (sqs_A100)；原因：完整88行与全部固定图已见，递归显著降低变化代理却少有PSNR改善，进行一次有界解释；这是适应性分析，不回写R59评价或伪称独立事前确认。

只读R59全部88已有输出缓存和R58固定GT；无新RAW/网络/训练/GPU或输出修正。所有场景/seed/方法不选择，分别固定主帧2–5及全8帧两种范围，共176分解行，不是176新质量配置。单参考GT的逐帧重复允许如下有限样本恒等式：

```
r(x,y,c) = mean_t(output_t) - GT
d(c) = mean_xy r
MSE = mean_c d(c)^2 + mean_xyc (r-d)^2
      + mean_txyc (output_t - mean_t output)^2
```

三项为全通道均值偏移、时间平均图的中心化空间误差、同坐标时间变化能量，均非负；不是统计独立因果贡献。按范围直接重算MSE，分解相对误差≤1e-9，否则停止保留失败。空间mean PSNR不是pooled MSE的变换，不以本分解替换原PSNR结果或重排名。汇总按四源等权MSE先聚合再取组分比例，不平均像素比值。

时间平均图误差还含参考噪声、渲染/曝光差、真实变化和微小错位；时间项也不是纯噪声。4/8帧population矩仅为样本恒等分解，不是无限采样均值/相机标定或统计偏差的无偏估计。尤其不将全通道DC项等同某个BN/bias参数或证明FPN主因。
