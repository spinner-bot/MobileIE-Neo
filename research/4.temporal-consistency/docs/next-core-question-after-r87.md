# R87后待核核心问题：更早共享特征中的几何信息，而非扩大度量矩阵

2026-11-17；Codex  (sqs_A100)。这是待先例/实现论证的下一问题，不是已登记的新实验/方法，也没有启动新训练。R87的正对角校准及R84/R74等旧STOP不解封。

R87保持12维z的RGB函数，匹配仍只观察z的可逆缩放，不能恢复生成z之前已丢弃的分量。原head先Conv5/PReLU产生12通道A，后Conv3将每个3×3的108维patch映射为12维z，再平方。可核假设是：恢复投影之外的早期空间信息，是否对几何匹配有用，而不必改变原恢复函数。这不是把D换成全矩阵或把同一z加宽。

一个需要定向先例核查的具体设计候选：从同一次前向的A另读一个3×3、stride4、4通道、无bias的可学习描述投影。原恢复卷积及全部原参数冻结，图像分支不读新描述，RGB映射因此保持；描述分支训练用已知合成几何/独立噪声，后续若有依据再接一个明确的因果非局部对应/状态算子，不能仅凭检索改善称视频收益。部署增加432权重，参数4075→4507；卷积约27HW MAC、1080p约.056 GMAC，均为解析预算而非实测或零开销承诺。前帧4通道quarter描述+native融合RGB理论3.25HW FP32，另有当前激活/求解/warp与框架workspace，不能冒充峰值RAM。

可比较恢复Conv3权重行空间与其正交补：W为12×108（不把bias误当patch方向），新权重若投影到ker(W)，在抽象patch线性代数里与原读出方向正交。卷积patch有空间依赖、A来自非线性变换，不能称已找到输入图像的真实无影响子空间，也不证明补空间有运动信号或低噪声。重建函数保持来自分支隔离，不来自这项正交约束；必须明确这一点。正交补只是待检验的归纳约束，不能预设其比普通描述符好。

在开实验前必须定向核共享encoder/任务隔离描述符、已知几何描述学习（如homography/匹配学习）、投影/补空间或正交任务分支的直接先例，不能以普通共享、正交约束或新增conv当创新。必要对照是同一A和相同推理形状的普通描述投影与受约束投影，报告实际训练自由度不同；再对原F0、half-FB及固定DIS共同质量/时序/完整成本评价。不能复用旧R84 hard matcher当作已经有资格的后端。

下一步应把这条信息路径及直接先例差异核实后，形成一个完整可运行的因果候选和有限正式预算，而不再添加一串全局度量、系数或小诊断网格。若机制不足则不启动；新颖性、视频收益、自然动态/手机/独立最终均未建立，长期目标active。
