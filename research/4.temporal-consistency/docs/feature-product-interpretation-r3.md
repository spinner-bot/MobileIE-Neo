# 双观测FST的解释：时间平均与差异惩罚纠缠

- 创建：2026-11-11 01:47 +08:00 · Codex  (sqs_A100)
- 触发：特征MSE、冻结网络RGB和受控训练三层证据并不支持简单的“独立噪声乘法必然更好”叙述。
- 定位：基础代数与本项目候选解释，不作为新方法或新颖性结论。

设同一位置两个已对齐特征为c、p，m=(c+p)/2，d=(c-p)/2，原FST为a*c²+b，其中a=w1*w2。则恒等式为：

```text
cross       = a*(m²-d²)+b
mean_square = a*m²+b
square_mean = a*(m²+d²)+b
cross - mean_square = -a*(c-p)²/4
```

因此，cross与mean_square的区别等价于按特征差异平方修正，既包含噪声差异，也包含运动误差、真实照明变化及卷积上下文变化。不能只将该项解释为噪声方差。观测相关性、非零均值及非线性传播都会改变其效果。

官方slim权重中head的a约-0.0003592982，body约-0.0018872726，两者为负。因此cross相对mean_square对该层输出添加非负的差异修正；后续门控和卷积仍可能改变RGB方向，不能直接等同“更亮”或“更少噪声”。逐层未加权平方误差不能跨层比较绝对大小，也不能代替RGB/感知误差。

当前训练使用original + gamma*(changed-original)。cross和mean_square分别学习gamma，使时间平均强度、差异修正和优化轨迹同时变化。即使cross最后略高分，也还不能把增量归因于方差去偏。

后续有辨识力的控制包括：同权重、同gamma切换三种算子；将平均与差异项的系数分开；对齐可靠度/曝光变化分层；以及单帧噪声方差补偿控制。应先看本轮六场景的成对增量和真实运动压力结果，再决定是否投入这些实验，避免为基础恒等式包装复杂模块。

与已有工作关系参见调研09、10：通道乘法、时序双线性和流式特征缓存均已有先例；论文贡献需要在实际问题定义、可解释适配、同预算强对照及效率收益上继续建立证据。
