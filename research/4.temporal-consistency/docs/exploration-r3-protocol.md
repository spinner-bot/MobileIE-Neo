# 第三轮探索：实际特征统计与状态更新解耦

- 创建：2026-11-11 01:27 +08:00 · Codex  (sqs_A100)
- 触发：用户要求持续自主推进、小步密集提交；第二轮尚不能支持结构路线定案。
- 身份：探索性诊断；沿用已查看的Kodak 01–12，不称盲测或真实视频证据。

## 深度：先检验跨观测乘法的前提

- 官方slim预训练模型，head/body的block1真实输出，clean参考为未量化、无噪声低光输入的特征。
- 12张图各固定中心128×128裁剪；64次噪声观测，组成32组互不复用的观测对。内部有效区域去除8像素边界。
- 两种条件：独立泊松/读出噪声；独立泊松+共享读出噪声（模拟固定扰动，不冒充真实传感器）。分别无JPEG和JPEG70。
- 共享读出条件保持每帧读出边际方差0.008²；JPEG条件的clean参考仍不压缩，因此压缩偏差也计入误差。
- 比较原自平方、双观测交叉乘积、双观测平均后平方，均以同一clean特征平方为参考；记录均值偏差、MSE、真实特征噪声均值/方差及成对协方差。
- 双观测控制都使用两个输入，原自平方仅一个；静态无错配是理想化上限诊断。网络特征偏差不为零时，不套用零均值高斯结论。
- 每通道保存统计，汇总按图像分组；不将通道/像素当独立样本宣称统计显著。

## 广度：门控与输出历史的重置分离

- 第二轮相同48个输入条件，原模型不训练；门控取逐帧/EMA0.9/检测重置EMA0.9。
- 输出取无融合、flow EMA0.7、FB置信度EMA0.7；两种融合各取保留历史/检测重置历史，共3×5=15方法。
- 检测器沿用亮度比1.35、缩略差0.5，禁止按本轮结果调整。光流、输入、有效区域与R2相同。
- 保存逐序列与逐帧PSNR、SSIM、边缘误差、GT相对时间误差及两类重置标志；分别看事件帧12、后续13–15及稳定阶段16–23，另看切换前0–11。
- 与R2重复方法逐序列核对；区分新增对照与重复审计，不把720行评价计作720个独立视频。

## 资源与决策

- 每次启动仍通过gpu_guard两次检查无计算进程、≤64MiB、≤5%利用率；本轮优先同组0–3，最多四卡。未满足则换空闲卡或继续CPU资料分析，不干扰他人。
- 固定算法预算，不设置墙钟超时。缓存权重/数据留.cache；代码、指标、过程资料、报告分别小步提交。
- 若交叉乘积相对平均后平方无稳定优势，不以基础统计动机直接立项；先检查偏差及运动错配。任何进一步训练在执行前补充协议。
- 状态重置必须考虑真实光照响应及画质，不能只降低帧差。继续保持多候选开放。
