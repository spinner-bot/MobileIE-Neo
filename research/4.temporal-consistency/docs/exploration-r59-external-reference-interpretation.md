# R59 外域冻结参考：结论与接续边界

创建：2026-11-12（+08:00）；作者：Codex  (sqs_A100)。依据完整正常终态、全部88序列/704逐帧、四张固定图及事后注册的缓存分解；无新增训练。

## 完整结果意味着什么

见[完整22行表](../report/exploration-r59-drv-native/tables.md)、[逐源结果](../results/exploration-r59-drv-native-attempt001/per_sequence.jsonl)、[条件](../report/exploration-r59-drv-native/conditions.md)。CNN仅读R58原曝光native；四官方train场景各8观察、一个长参考。主目标统一为帧2–5，FastDVDnet均获得五个不同源帧，全8结果同时保留。

原公开MobileIE/Nano raw主PSNR为16.3243/16.9717dB；适配MobileIE seed0/1为15.7171/16.9794，适配Nano为14.9015/15.3347。Nano在此前SYN/ND适配的增益没有迁移到这批相机资料，相对原公开Nano为−2.0702/−1.6370dB；MobileIE两seed相对其原公开权重为−0.6072/+0.6551dB，方向不一致。不能将单一域、单一seed的提升写成普遍改善。

R53 FastDVDnet raw为13.9977/15.0636dB，相邻RGB变化代理1.1405/1.2199；它有五帧输入和未来2帧、2479096参数及不同预训练/训练计算，sigma15/255也未在本资料标定。低变化代理没有补回画质差距，不能以此宣布视频模型或其架构一般无效。

经典recursive .5能明显减小变化代理，但除名义EV数据控制外主PSNR变化都很小。MobileIE原公开16.3243→16.3216，Nano原公开16.9717→17.0221；两适配MobileIE只增加约.016dB。RGB gate没有产生新的独立优势。这说明在这批资料上仅继续追求平滑不足以解决主要空间失配，不能把代理下降直接写成方法成功。

名义EXIF补偿使用配对长参考的曝光元数据，raw14.7957/recursive15.2797dB；它未实测匹配参考亮度，不是公平可部署方法、纯去噪任务或CNN新输入。没有以GT拟合或删源修复它。

## 有限分解提供的边界

[分解全表](../report/exploration-r59-drv-native/decomposition001/tables.md)仅重用全部88缓存输出；主4帧/全8帧共176分解行，0新CNN/SGD/GPU。对于固定参考，MSE精确分成全通道均值偏移、时间均值的空间残差、样本时间变化三项；最大相对闭合误差1.97e−15。等权先汇总四源MSE再取比，不以PSNR均值反推MSE。

主4帧神经raw的均值偏移占80.685%–86.314%，时间变化占0.0304%–1.0689%。后处理主要削减后者，持续的曝光/颜色/空间差异保留。因此新的时间机制必须同时保持或改善空间映射，不能只优化低变化代理。现有证据没有定位到BN、偏置项、ISP或特定噪声；有限采样项不是无偏统计噪声估计，也不是从GT可直接学习到的部署校正量。

这是看完完整结果后明确登记的适应性分析，不独立确认一个新假设、不改变输出或旧门槛。四静态官方train场景/自定义ISP/4唯一参考不足以得出标准基准、动态闪烁、手机或最终泛化结论。
