# R61 决定：不扩近邻二次差分/去偏网格

记录：2026-11-13T00:02:55.270620+08:00；作者：Codex  (sqs_A100)。精确符号计算正常完成，三项原文定向读取与旧R5/R6/R7协议/完整表均已回查；本轮没有新CNN/SGD/GPU或图像采样。

1. 不重启TSM式前三通道/学习gamma：R5/R5b已实际训练，R7也有通道/融合控制。旧预算不等于原TSM完整复现，但不足以把相同设计当新研究。
2. 不为F=a*u²−g*(u−v)²+b新增g网格/模型。它是常系数两观察二次、对角一致且在同均值处无历史一阶响应时的完整族；独立同方差Gaussian下线性方差项4*a²*mu²*sigma²固定，g=a/2去偏却与raw方差相同。改变真实均值又带来−g*Delta²偏差，相关噪声还破坏简单去偏。12个残差恒等0，运行0.331800秒，详见完整结果runtime，不能称实验性能收益。
3. 该决定是结合旧R6实际去偏质量退化与本次基本代数作出的投入取舍；不声称所有g都必然差、不否定自适应/多帧/非Gaussian方法，也不推导整网方差/PSNR下界。原权重、数据、已失败的R28/R44等门槛均未更改。
4. “亮度增强后的噪声均值补偿”已有直接NBC视频先例；其校准先验不能当作本项目已获得。“冻结空间网络+时间模块/伪标签”也已有TAP，R37失败不能否定全部此类方法。具体假设和实际阅读范围见note47，不包装基础恒等式为创新。
5. R59长期参考下的平均通道误差不是已识别的噪声期望偏置。下一有效机制须交代统计如何可部署获得、如何区分真实变化，以及信息增量和完整成本；没有这个证据就不追加校准/损失/系数训练。当前尚未建立新的方法候选。
