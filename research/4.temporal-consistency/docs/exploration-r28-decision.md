# R28决策：冻结post_transport主方法路线

记录：2026-11-12 04:24 +08:00；作者：Codex  (sqs_A100)。依据为已完成的[注册协议](exploration-r28-protocol.md)、[4416行共同CUDA结果](../report/exploration-r28/tables.md)、[原生图](../report/exploration-r28/native_quality_stability.png)及[312行外部CPU结果](../report/exploration-r30/tables.md)。全部使用固定4000步，不选里程碑或最佳seed。

## 决定与边界

post_transport不再作为主方法候选；不追加该算子的训练时长/seed/alpha网格，不恢复其它已训练seed0算子的全面搜索，不扩大CPU逐bit诊断。已完成的所有模型、失败/拒绝准入和不利结果保留。论文目标继续，不能将这次负结果写成找到方法。

预设筛查要求相对强post .5，PSNR差不低于-.05dB且时序误差至少降低10%；真实历史与current单帧部署分别判断。原生域双目标/双seed均未通过；既有六评价分组的主要raw配置也未通过。六分组和46输入条件含重用场景，不是46独立视频或六独立基准。外部DAVIS开发资料的双seed同样未通过，且actual相对同权重current+post没有建立联合优势。

原生双seed均值：Charb actual相对plain+post为PSNR -1.9202dB、时序误差+0.07832；MSE为-.2567dB、+0.13541。相对自身current+post，Charb/MSE actual的PSNR约-.06168/-.02474dB，时序约+.00804/+.01506。MSE在SSIM/边缘上有小幅权衡，不宣称四项指标全部被支配；但预设主要门槛明确失败。个别seed的PSNR正差也不能替代时序改善。

这只否定本任务、数据、固定4000步预算及实现下的主方法投入价值，不是所有时间算子永远无效的证明。延长训练可能改变映射，却没有现有证据说明会形成对同权重经典post的必要优势，因此不继续沿相似算子追微小差异。

## 对后续方向的约束

1. 实际post_transport仍依赖flow/warp和12通道历史特征；4075预测参数不等于零推理开销。独立过去输入不能精确代数折叠成当前单帧函数；current是不同部署映射，不再以“折叠历史”包装它。
2. 后续以总计算/状态/端到端时延预算约束，允许重新分配原骨干的空间计算以容纳真正因果状态；不把精确4075参数或零额外开销当作已由用户规定的唯一可行路线。参数、MAC和手机延迟分别评估，不能互相替代。
3. 先补具有真实动态的公共训练来源及强单帧/经典post/已发表视频参考，再选择少数骨干重构。目标是改变信息处理和噪声响应，不是给原网络继续拼同类平均模块。
4. 对更一般的乘积/门控和流式状态先读一手先例，做同容量空间控制及history替换；已知乘法、时序移位、蒸馏或普通噪声正则不能单独当创新。
5. 已取得的三手机片段与DAVIS三开发片保持固定，方法评价与最终保留测试分离。外部DEV可暴露泛化问题，不能按它追选loss后宣称独立确认。暂不将被否定路线的全手机推理网格当新的研究重点。

优先接续：核查轻量门控/流式网络的结构与计算分配；登记不含现有三开发视频的公共动态训练池；用少量匹配预算的空间/因果骨干检验是否学到真正历史增益。正式新方法尚未确定，训练前另行登记，不自动扩大未证实候选。
