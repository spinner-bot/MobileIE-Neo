3.1. MiVideo
Figure 1. The architecture of RetinexFormerRefine proposed by
MiVideo.
Description:We adopt RetinexFormerRefine, a
lightweight variant of RetinexFormer [6], as our base
model, as shown in Fig. 1. The architecture follows
the RetinexFormer design with a reduced channel size
and a convolutional downsampling strategy. To enhance
representation capability, we incorporate Channel Atten-
tion (CA) and OCAB modules into the original IGAB
blocks, forming an improved IGAB V2. In addition,
we employ structural reparameterization, which utilizes
multi-branch structures during training and converts them
into a single-branch structure during inference for higher
efficiency.
Implementation:The model is implemented based on the
BasicSR framework [74] and trained on 8 NVIDIA A100
GPUs. We use the AdamW optimizer, cosine annealing
learning rate scheduler, EMA, and learning rate warm-up.
Training is conducted in three progressive stages with in-
creasing input resolutions, and structural reparameterization
is introduced in the final stage. The loss functions include
L1, LPIPS, DISTS, SSIM, and Weighted TV . The training
data is aligned using SuperPoint [16] and LightGlue [42],
and a subset is reserved for validation. Training is iteration-
based with early stopping, and the best-performing model
on validation/test sets is selected.

3.6. NUDT DeepIter
Description:We proposeFinalEfficientEnhancerV2, an
efficient U-Net based architecture for low-light image en-
hancement following the encoder–decoder paradigm [12,
82], as shown in Fig. 6. The network consists of three main
components: an encoder with Partial Convolution (PConv)
blocks for efficient feature extraction, a bottleneck with
Dark Enhancement Blocks for adaptive low-light process-
ing, and a decoder with skip connections to preserve high-
frequency details. The PConv module, inspired by partial
convolution [43], processes only a subset of channels to
significantly reduce computational cost. Additionally, Uni-
fied Inverted Bottleneck (UIB) blocks derived from Mo-
bileNetV3 [29] are used for lightweight design, while Dark
Enhancement Blocks incorporate adaptive gating mecha-
nisms similar to NAFNet [11] to selectively enhance dark
regions while maintaining well-lit areas.
Implementation:The model is implemented in PyTorch
(Python 3.8) and trained for 600 epochs on the LOL
dataset [80]. We adopt the AdamW optimizer with an ini-

3.7. HIT-LLIE-team
Description:We propose an ultra-lightweight fully convo-
lutional network, termed MobileIE-6Ch, for efficient low-
light image enhancement, built upon the MobileIE base-
line [83]. The architecture introduces three key compo-
nents: (1) a unified 6-channel output head that jointly mod-
els RGB illumination and noise residual, (2) a Multi-Branch
Reparameterization (MBR) backbone for enhanced feature
extraction, and (3) a dual-attention modulation module for
adaptive feature refinement. During training, multi-branch
convolutions (e.g.,5×5,3×3,1×1, and asymmetric ker-
nels) are employed and later structurally reparameterized
into single convolutions for inference, following [18], en-
abling a highly compact model with negligible inference
overhead. The network follows a Retinex-based formula-
tion [37], where the enhanced image is reconstructed via
predicted illumination and residual components, allowing
simultaneous brightness enhancement and noise suppres-
sion.
Implementation:The model is trained using the Adam op-
timizer [35] with a batch size of 16 for 800 epochs under a
Distributed Data Parallel (DDP) setting. Training is divided
into a 20-epoch warm-up stage (learning rate1×10 −6) and
a main training stage (initial learning rate1.5×10 −4) with
cosine annealing scheduling [49]. A hybrid loss function is
adopted, combining Charbonnier loss [9], SSIM loss [77],
color consistency, and frequency-domain constraints. High-
resolution images are processed using random cropping
(768×768patches), and a 5-fold cross-validation strategy
is applied. Additional stabilization techniques include gra-
dient clipping (threshold 0.5) and careful illumination reg-
ularization during warm-up.
