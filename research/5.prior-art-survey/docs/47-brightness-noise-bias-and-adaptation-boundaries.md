# 亮度噪声均值补偿、独立性与冻结空间先验

创建：2026-11-13T00:02:08.841856+08:00；作者：Codex  (sqs_A100)。定向回查已有实验与三项一手原文；不是新方法登记，不重开TSM/平方修正/训练长度网格。

## 实际读到的直接先例

[Araki与Minewaki，Video noise reduction using noise bias compensation](https://www.jstage.jst.go.jp/article/gigaku/11/1/11_11005/_pdf/-char/en)，原文§2–3、页2–4：明确处理亮度调整产生的噪声均值偏移，以8bit补偿表校正，视频按特征分组共享表。表依赖增强前无噪视频的直方图和给定噪声分布/方差，不能当作从未知夜景直接得到的无监督校准。官网标卷年2023，在线2024，并列2026 PDF修订；本次按当前PDF读取。未复现作者成绩。

[FC-AIDE，arXiv1807.07569v4](https://arxiv.org/html/1807.07569)，§3–4：像素多项式系数由排除该像素的上下文产生，其无偏风险需要相应独立/对称噪声条件；专门构造QED以维持条件独立。MobileIE一般特征并不满足这些约束，不能直接搬用无偏性，也不能将二次映射/单图自适应作为空白点。

[TAP，arXiv2409.11256v1](https://arxiv.org/html/2409.11256v1)，§3.1–3.2/4.1：冻结预训练图像去噪器，在多尺度skip插入对齐/融合模块、零初始化残差，再逐级用伪干净图与已知噪声重退化训练；原文区分训练集适配与test-time设置。它证明这类方法已有先例，不能以本项目R37一个冻结小适配器的失败否定整类，也不能冒称复现其完整多尺度/噪声流程。

## 回查项目而不是重新试一遍

R5/R5b已经训练单body层前三通道、固定/可学习gamma的TSM式控制；R7还做过通道覆盖和前后融合。当前没理由将它当新设计重开比例/seed/长度。

R6/R6b已做平方去偏、线性化、保持条件均值的中心化控制。旧官方权重raw19.39885dB，debias_head18.54834、debias_body16.32744；centered_head20.53087，但噪声SD15.51523对raw15.78449，且适配权重并未一致减少波动。这里是旧24静态条件的探索结果，非当前强权重/实际视频结论；单纯去偏并非空白路线，也不能由R59高均值偏差占比反推其一定有效。

R59的“输出—长参考全通道均值偏移”与NBC的“给定干净输入/噪声下增强器期望偏置”不是同一个量。前者还含曝光目标、颜色、相机ISP与参考差异；目前没有证据把81%–86%都归到噪声均值。R60无GT动态夜景也不提供这种归因。

## 基础代数得到的更窄排除

R61独立协议/精确符号核对表明：若常系数二次F(u,v)在相同输入时等于a*u²+b，并对历史的一阶导在u=v处恒为0，则只能是

```
F(u,v) = a*u² − g*(u−v)² + b.
```

独立同方差Gaussian噪声下，该族方差的线性项始终是4*a²*mu²*sigma²，不能靠g缩小。g=a/2局部去偏，但方差恰与原平方相同；真实均值不同还增加−g*(mu_t−mu_p)²偏差。相关噪声时局部偏置改为[a−2g*(1−rho)]*sigma²。因而不能把“零一阶滞后+平方差补偿”描述为同时免费解决主导线性噪声、真实变化和噪声偏置。

这是本项目基础推导，经SymPy核对12个残差恒等0，0图像/MonteCarlo/CNN/SGD/GPU，不是新理论或全网下界。MobileIE非Gaussian特征、下游门控、真实运动、空间相关和自适应系数不在该证明范围，旧R6的body归属量也不是当前模型的普遍方差比例。
