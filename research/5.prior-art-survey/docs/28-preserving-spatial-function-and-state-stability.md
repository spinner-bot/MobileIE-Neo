# 保留空间函数与有界递推：下一有限假设的先例边界

创建：2026-11-12T07:26:23+08:00；作者：Codex  (sqs_A100)。R36评价运行中；不以部分DEV表现选参。

[Net2Net原始摘要](https://arxiv.org/abs/1511.05641v4)已明确函数保持的网络转换。因此保留已有映射、零幅度残差初始化本身不是本项目创新。这里只读摘要，不声称实现其加宽/加深转换。MobileIE现有4075参数强底座应保留，不能再把非等价SVD压缩引入的潜在损害当视频适应必须支付的代价。

[Recurrent Video Stability v3正文](https://arxiv.org/html/2010.05099)阅读摘要、I-A及II稳定性定义/预防讨论。该工作研究长视频递归失稳及谱/稳定秩约束，说明短窗口训练和几十帧有限输出不是长期稳定性的证明。SRN-C是既有方法，本项目没有复现，也不将有界凸融合或谱约束包装为全新理论。

下一有限假设：保留完整强原始骨干并冻结其权重，用全空间分辨率、低通道半精度状态提供内部FST前的历史创新。用可训练正交投影/转置读回、零幅度初始化，避免替换原body或把完整空间信息预先平均池化。小尺度只用于预测offset/gate，采样的历史本身保持全分辨率。这个组合是待检验架构，不是已经确立的新方法；投影、warp、门控、半精度或函数保持均有先例。只有实际优于强传统递归且满足成本约束，才值得进一步深挖差异与完整相关工作。

不要作如下不成立的推理：冻结CNN不代表无额外推理；FP16不代表没有量化误差；全分辨率不代表保持所有通道信息；状态有界不代表不同初始状态会收敛；门控/offset依赖状态时不能仅用一个gate上界就声称整个递推的Jacobian收缩。初始等于原函数也不保证训练后实际历史映射不退化。
