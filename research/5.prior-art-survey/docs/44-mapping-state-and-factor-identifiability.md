# 映射状态的先例、等价控制与因子不可辨识

定向阅读与代数核对：2026-11-12；作者：Codex  (sqs_A100)。R56/R53仍按原流程推进；本笔记0新CNN/0SGD/0新数据，不登记新方法或启动映射EMA训练。

## 实际读取的先例

[FastLLVE v1](https://arxiv.org/html/2308.06749v1) §3.1–3.2及会议元数据：是ACM MM2023，不是早期索引猜测的ECCV2024。3D编码视频，生成视频相关的基LUT混合权重及强度图，再查表映射，可附加去噪。它不能仅因逐帧应用映射就归成逐帧独立网络或RNN；本次未复现实现/延迟或核实特定窗口的严格因果性。共享增强映射已经有直接先例。

[IJCAI2025一致分解原文](https://www.ijcai.org/proceedings/2025/0238.pdf) §3.1–3.3：监督网络直接预测正常光照的两种分量；利用正常光视频的匹配约束反射分量，并施加照明的空间连续性和跨帧深特征交互。不能把其训练对应假设直接当作可部署低光motion，也不能将“反射跨帧稳定/分解照明与外观”重新命名为创新。未复现该网络。

[TempRetinex v2](https://arxiv.org/html/2511.09609v2) III-A/B、III-D、S11：包含分位统计亮度预处理、显式光流反馈及多尺度约束；反向推理属于离线双向平均，与仅过去反馈不同。作者明确讨论快速灯光变化及显式flow成本的限制。本次不搬用其HM/RI表为共同成绩，也未复现模型。曝光分布归一和因果反馈本身都有先例。

## 残差场平均的一个必要控制

以下为本项目基础代数，不是上述论文的结论或新理论。记同一接受域内线性warp为W，当前输入x、过去输入p、逐帧增强器f，d(x)=f(x)−x。令a=1−α、b=α，比较：

```
y_RGB = a f(x) + b W f(p)
y_delta = x + a d(x) + b W d(p)
y_delta − y_RGB = b (x − Wp)
```

所以保留当前输入、只平滑增强残差，并非凭空增加历史信息，而是相对RGB平均加回原输入创新。它可以重新引入噪声/真实变化，不能仅凭较少拖影解释成更好的对应或新机制。式子比较额外最终clamp之前的输出；clamp/接受域变更另产生差异，不能混作理论等价。

在理想对应、同一固定标量增益f(x)=g x、g>1的特例中，残差平均恰等于RGB平均使用更小历史权重α_eff=α(1−1/g)。若g=4、α=.5，α_eff=.375。这个特例不是一般非线性/空间变增益结论，却已足以说明：只胜过RGB固定.5不能证明残差域独立收益，应至少比较匹配α及已有可学习RGB控制。不为该重命名另开训练。

## 分开平均乘法因子并非平均同一映射

Nano的增强调整为D=L C，其中L标量、C为三通道；它们是自由调整场，不是由独立GT监督得到的唯一物理照明/反射。仅靠乘积监督，在不额外限制因子函数时不能排除L→sL、C→C/s的尺度重参数化。固定网络类未必能表达任意时变s；这不是对具体模型可达函数类的断言。因子没有因此获得唯一物理语义，不能直接把其波动都当真实照明或噪声。

已在同一坐标的因子满足逐通道恒等式：

```
a Lt Ct + b Lp Cp − (a Lt + b Lp)(a Ct + b Cp)
    = ab (Lt−Lp)(Ct−Cp)
```

若两帧乘积均为1，第一帧(L,C)=(1,1)、第二帧=(4,1/4)，α=.5时因子平均后的乘积为1.5625，映射平均仍为1。因子EMA甚至可能制造原乘积没有的变化；这只是重参数化反例，不证明实际训练模型必然采用这种变化。

若过去因子分别经双线性W，对照输出真正包含W(Lp Cp)，还要补上：

```
W(Lp Cp) − (W Lp)(W Cp) = Cov_w(Lp,Cp)
```

这是插值权重下的交叉协方差，可正可负；不能原样沿用自平方的Jensen非负方差解释。全差包含时间交叉项abΔLΔC与b Cov_w。为达到原乘积平均而维护这些矩，可能只是另一种实现已有映射平均，并不自动带来新表达能力/质量或免费状态。
