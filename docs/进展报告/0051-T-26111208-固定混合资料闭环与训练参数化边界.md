## 固定资料检验完整执行

[协议](../../research/4.temporal-consistency/docs/exploration-r40-mixed-anchor-protocol.md)在训练前登记。只改R34原始骨干每步四窗口中的两个为既有真实配对窗口，50/50单比例、同4075参数、官方slim初始化、MSE/Adam1e-4/clip1/B4×4帧128/4000预算，不改变合成退化、结构或加时序损失。纯合成控制重用已完整完成的R34 original，不重复8000更新。

真实训练12视频/384文件先核对自有路径、摘要/解码/配对和划分；与原采样器前两个合成窗口一致及混合反向CPU门槛通过，0次门槛优化。两个seed在GPU0/1启动，各在完整CPU源加载后、初始化CUDA前又双采样确认空闲，无别人计算进程/显存占用；只用同组两卡，不以墙钟截断。两个seed各4000正常结束，训练主循环541.410/542.088秒。

[训练完成核对](../../research/4.temporal-consistency/process/exploration-r40/training-completion.json)确认各4000连续trace、16000窗口（合成/真实各8000）、57/12源视频实际覆盖，全部步的合成窗口上下文等于R34对应前两个。没有CPU Adam或逐tensor训练重放。协议/代码、来源、门槛、准入、所有检查点、完整trace、窗口和终态stdout按文件提交；[过程日志](../../research/4.temporal-consistency/process/exploration-r40/journal.md)记录接续与实际执行。

finalize001只在两个guard正常终态后加载最终权重，双seed共同CPU评10条件×3输出（raw/finite/recursive），60新质量行/20CNN序列，复用96同CPU强参考，总156行。两域分开，未读取最终保留像素、未用手机无GT样例调参。

## 结果：固定混合没有解开冲突

|两seed均值|合成raw PSNR|实拍raw PSNR|合成recursive PSNR / Temporal↓|实拍recursive PSNR / Temporal↓|
|---|---:|---:|---|---|
|R26旧方案|23.661207|27.138015|本轮不另推断|27.014906 / 2.430531|
|R34动态合成|26.234161|23.453047|26.610354 / 6.734680|23.379556 / 2.429468|
|R40固定混合|25.133622|24.860774|25.803268 / 7.105806|24.784900 / 2.540240|

[全表](../../research/4.temporal-consistency/report/exploration-r40-mixed-anchor/tables.md)保留PSNR/SSIM/temporal/edge、两个seed/逐条件与官方权重。相对R34，两个seed真实raw增加1.061971/1.753482dB，合成下降1.055170/1.145909dB；两个注册门槛都未过。对更强R26实拍，两个seed仍低1.657163/2.897319dB。不是只看补回的一侧，也不拿旧CUDA数值拼对照。

[跨域图](../../research/4.temporal-consistency/report/exploration-r40-mixed-anchor/cross_domain.png)显示三个raw方案均有不同取舍；R40保住较弱域，但没有满足预设联合要求。各域最强参考来自不同权重，这个参考包络不是自动选域的单模型。不能把额外的最弱域描述改成事后成功门槛。相比R34的控制只替换训练窗口，较早R26还含其它训练差异，不孤立归因。

[决策](../../research/4.temporal-consistency/docs/exploration-r40-decision.md)：保留R40作为固定折中基线，停止混合比/loss/LR/时长/seed局部搜索；不增加同类时间结构，也不由本轮宣称两域不可兼得。基线或资料进展不等于论文创新。

## 原始训练形式与公开数据接口

回读上游`main.py`、MBRConv/BN及2号历史短程训练，补充[训练参数化边界](../../research/4.temporal-consistency/docs/architecture-and-video-research-plan.md)：服务器近期是slim微调，没有完整复现官方多分支、双头warm-up和长程调度。部署形式相同不能代替训练范式公平；BN固定统计下的空间折叠也不等于train模式batch统计或优化过程等价。下一有限强对照可审查函数保持地恢复原训练参数化，但须先登记数据/优化预算、初始化/BN/fold门槛，不能把既有结构当创新或复活位级工程诊断。

[有界来源核查](../../research/5.prior-art-survey/docs/29-raw-srgb-benchmark-boundaries.md)精读DarkVision的RAW/TIFF、不同照度采集和手机输入标定范围。同名HF仓库身份未与论文作者交叉确认，出现fake标签，不纳入低光配对资料、不读像素；HF搜索接口禁用时改用作者/出版页面，详情接口仅验证仓库存在。SDSD作者说明仍可读，本轮不重复大文件访问，也未补齐DID/BVI像素。
