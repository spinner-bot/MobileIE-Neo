# 0015｜因果骨干与同容量反证

创建：2026-11-11T16:40:13.835997+08:00；作者：Codex  (sqs_A100)；原因：用户设置远期研究目标，继续0014后的骨干适配深挖，并记录架构收益的归因检验。

## 当前判断

**降低本轮低分辨率线性历史分支的优先级。** 它的主要增益能被位置和参数匹配的单帧分支复现；添加明确时序监督后，替换历史仍几乎不改变结果。固定时序移位存在明显事件退化，学习型移位则有域间取舍。当前没有被证明的新视频方法。

发现一个有用的强空间基线：FST后加入当前帧低分辨率线性修正，真实域相对同预算原架构 +0.67664 dB，6/6片段为正。它新增108参数和约33%本机模型延迟，是后续必须比较的空间容量/上下文控制，不将该提升写成时间建模成果。

远期目标保持进行中：[目标记录](../../research/4.temporal-consistency/docs/long-term-goal.md)。main继续核心研究，演示支线保持由claude code (local)负责。

## 主要结果

以下为raw、两训练种子平均。时间误差是扣除GT帧差后的残差，越低越好。

| 同预算模型 | 实拍PSNR | 实拍时间误差 | 旧合成PSNR | 旧合成时间误差 |
|---|---:|---:|---:|---:|
| 原架构 plain | 16.50662 | 2.42026 | 17.11115 | 15.86217 |
| 空间双线性 | 16.60476 | 2.42099 | 17.15759 | 15.86704 |
| 历史双线性 | 16.60389 | 2.42234 | 17.15767 | 15.87655 |
| 空间post | 17.18326 | 2.38982 | 17.26396 | 15.75495 |
| 历史post | 17.18349 | 2.39685 | 17.26331 | 15.75306 |
| 学习型TSM | 16.54745 | 2.40915 | 16.63218 | 15.58414 |
| 固定TSM | 16.46043 | 2.87397 | 17.07606 | 16.35944 |

历史双线性相对同容量空间版，实拍 −0.00086 dB且时间误差更高。同权重causal−current仅 −0.00026 dB，说明训练后的分支没有取得可观测的独立历史质量收益。历史post相对同位空间post仅 +0.00023 dB、3/6为正，时间误差6/6更高；相对其同权重current替代则 −0.00115 dB。不能把相对plain约0.677dB提升归因历史。

增加仅合成对的系数1、精确平移GT残差时序项后，plain实拍PSNR变为17.04189，时间误差2.31480；旧合成PSNR降至16.11942，时间误差14.56946。实拍提升4/6为正，video118的+2.634dB占均值提升很大部分；SSIM也从.80617降为.79692。时序训练存在质量与域迁移代价。

相同监督下，历史双线性实拍17.12735，但同权重causal−current仍只有约 −0.00018dB；时间误差更高约.00123。学习型TSM相对plain时序训练，实拍−.00841dB，旧合成+.03542dB，没有形成明确结构优势。新增时间项的训练策略与STCL已有工作相关，见[调研13](../../research/5.prior-art-survey/docs/13-training-objectives-and-causal-state.md)。

## 事件与后处理反例

切换frame12：plain平均PSNR19.64353，空间post19.79369，历史post19.69850，固定TSM14.79272。固定移位把旧结构带入新场景，整片均值会掩盖这个退化。光照突变时固定TSM的平均亮度响应比约−.067；所有数值对应本轮特定合成压力条件，不能推广为普遍模型排名。切换交界参考mask为空，时间误差保留空值，没有补0。

半分辨率共享增强域FB、alpha=.1仍保留强基线：空间post+half实拍17.18407/时间2.25312；旧合成17.48230/13.98532。官方原模型+half旧合成17.62392/14.35815，前者PSNR并未超过后者。共享motion来自官方teacher，其他候选若部署使用它需要额外teacher前向，不能算免费。本轮未重测这些组合完整CPU/GPU流程，不把模型事件计时当端到端速度。
