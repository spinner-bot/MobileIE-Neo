# 0023｜前置历史与训练状态分布反证

创建：2026-11-11T19:35:27.050417+08:00；作者：Codex  (sqs_A100)；原因：核验R11 pair训练一半self历史是否是时域收益小的主要原因。

补充前置历史没有解决主要问题。训练总指标随上下文变化，但同权重真实历史增益仍小，部分实拍/原生结果变差。下一轮转向原生区域与缩小图的成对深度训练，不把普通burn-in当创新，也不继续围绕本假设增加更多变体。

## 唯一改变与检查

保留R5/R11每步任务当前/GT、强Adam1e-3/global clip1/Charbonnier .001及4975参数。实拍第一任务帧历史取t−2、边界0自身；第二历史仍t−1。合成前置crop减offset，独立噪声rng1401300000+seed*1000000+step，原两当前帧与标签直接复用旧生成器。

新增raw/对齐concat各两seed1000=4000时域更新；copy seed0额外1000重放，总5000更新、50 checkpoint。原监督身份逐条匹配，两个CPU检查验证合成像素/GT/metadata精确不变和边界索引。空间1000步每步task、梯度norm、aux norm及最终权重最大差0，通过预设1e-7；复用copy双seed参考，不声称seed1另做完整重放。

self历史任务比例由50%变为seed0 64/4000=1.6%、seed1 69/4000=1.725%，二seed合计1.6625%。不声称精确匹配部署边界分布。对齐仍使用固定官方teacher/半尺度FB，共8000训练pair，不用GT或已知合成flow。

46旧条件、同R11推理路由及motion、双seed、causal/current、reset与raw/half01，新增1472行，复用2208 R11参考；首帧history/reset像素差0。46条件不是46独立视频，native与resize共享4dev。
