# 0027｜监督配对几何反证与数据准备

创建：2026-11-11T21:18:16.088544+08:00；作者：Codex  (sqs_A100)；原因：检验监督配对是否是近期模型细节/时域结果的主要混淆。

固定检查未支持明显整体整数平移主因。100原始配对中97最佳零位移；两个训练帧为1像素偏移，另一个dev候选有明显歧义。四个固定模型输出最佳位移均零，GT辅助平移没有提高其PSNR。已有评价/GT保持原口径，下一步检查时间冗余和噪声相关性，不继续围绕本假设扩宽搜索。

## 固定样本与方法

12训练目录每段frame0/8/15（36）及4dev原生512×288的全部16帧（64）；另4dev/frame8的既有R14 native plain seed0/4000输出，共104项。这些是重复探索条件，不是104独立视频。原384训练PNG逐SHA，native cache/显示数组/104地图SHA核验通过。

灰度Gaussian sigma1、Sobel3有符号xy，两通道归一化互相关；GT margin48模板、输入margin16搜索，dx/dy各±32整数，无wrap。记录零/峰值NCC、排除半径3次峰和边界；常量纹理标退化而非伪满分。预设peak≥.3、gap≥.01、不命中边界仅为诊断标记，所有行保留。三个CPU fixture验证位移方向、亮度仿射和退化保护，独立重算所有地图argmax/零位置完全一致。
