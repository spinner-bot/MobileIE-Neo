### 2.2 可见性分析（60 帧，真实退化）

| 指标 | 输入 | MobileIE 输出 | 放大 |
| --- | --- | --- | --- |
| 像素对齐帧差均值 | 3.23 | **18.24** | 5.6× |
| 中位数 | 2.33 | **15.33** | — |
| p95 / p99 | 9.0 / 15.0 | **42.7 / 56.3** | — |
| 超过 8/255 像素比例 | 6.7% | **77.0%** | — |
| 超过 16/255 像素比例 | 0.7% | **47.2%** | — |
| 逐像素时间标准差 | 2.69 | **15.14** | 5.6× |
| 平坦区 / 纹理区残差 | 3.63 / 2.90 | **18.14 / 18.56** | — |
| 时间噪声 >3 Hz 功率占比 | 80.5% | **80.4%** | — |

结论：

1. 闪烁在空间上**普遍存在**（77% 像素超过 8/255），不是少量离群点；
2. 平坦区与纹理区同样严重，平坦区抖动更易被人眼察觉；
3. 时间噪声为**宽带**（80% 功率 >3 Hz），符合“逐帧随机噪声被网络放大”，而非慢速亮度脉动；
4. 这解释了“肉眼看视频不够明显”：残差大但空间随机、时域高频，需要帧差放大/局部裁剪/时序曲线才能稳定展示。

## 3. 结论

- 选题空白成立：**MobileIE + 视频时序一致性**尚无直接工作；
- 方法主线建议：**训练期时序一致性损失（推理零开销）**，必要时配合可重参数化的轻量帧间分支；
- 最大风险仍是“后处理够用”，评价协议已把快速运动、无拖影、低延迟列为主指标；
- 所有后续对比必须与 EMA/光流 EMA 在同等延迟下进行。
