# 0026｜多尺度骨干与独立历史反证

创建：2026-11-11T21:08:51.096349+08:00；作者：Codex  (sqs_A100)；原因：检验空间层级是否使真实时间信息获得独立收益，并核算额外成本。

增加空间层级没有建立一致的真实历史优势。raw模型在原生dev整体PSNR较高，但把过去替换成当前后几乎保留该收益，时序误差反而更低；对齐历史的轻微稳定性收益伴有质量损失。本轮是标准encoder-decoder机制参考，不是新颖性声明，也不能否定更充分训练的所有视频模型。下一步优先核查监督配对与可用时间冗余，而非继续扩大同类结构排列。

## 设计与恢复

官方head/FST/gate/tail基础上构建半尺度24通道共享编码器、双帧concat和带当前skip的decoder，24955参数。spatial两路当前、raw history真实前帧、aligned history共同teacher半尺度FB对齐，三者容量/初始权重相同，一过去零未来。全参数Adam1e-3/global clip1/Charbonnier .001，native320×180、原R14完全相同监督/ROI/合成和前置历史。三类双seed4000，共24000新更新，固定1000/4000全部评价，24 checkpoint均审核通过。

最初扩大通道的单decoder在GPU初始化超出原2e-5门槛，两个任务0更新停止。独立数值诊断后使用数学等价的分块卷积和，保留原窄卷积计算次序；不放宽门槛、不改变TF32。六组GPU初始化输出/task差0。另一次诊断device错误也留档；共3次失败，均无训练更新。模型4项与reset/因果3项CPU检查通过。
