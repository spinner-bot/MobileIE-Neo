# 0035｜冻结全局通道读出干预

创建：2026-11-11T23:17:40.150562+08:00；作者：Codex  (sqs_A100)；原因：R23全局RGB误差项不等于已定位HDPA，用固定节点干预核验，不凭误差分解设计新模块。

当前全局门控替代不能统一修复聚合训练的质量损失。四模式PSNR变化有正有负且逐片差异较大，均值量级约-.071至+.093dB，不能解释或补回此前约1dB的主差距。时间误差均值稍降，但远不足以把它当主方法；本轮降低直接“保留当前gate即可解决”假设的优先级，接续同接受域的GT估计对应敏感性诊断。

## 一个节点、完整预算

R21四模式×双seed4000×四native×16帧，冻结权重；先用同网络当前输入获得GAP→Conv1→sigmoid的12通道g_cur，再替换真实history映射的att输出。body输入/输出不改，空间att1公式不改但值可因上游gate变化，这属于干预下游作用。post两个共享映射分支均用g_cur，当前分支本来相同。g_cur不读GT，GT仅评价/误差分解。

三路径current/original causal/current_gate共96行/1536帧；前64序列/1024帧正式CPU指标重放最大差0，32新增干预；640组body逐像素/哈希等值验证通过。首帧最大差0；MSE闭合8.17e-16、PSNR恒等式7.11e-15dB，均未放宽协议门槛。CPU139.813s、RSS约1.07GiB、CUDA未初始化，无新训练/测试素材。

## 接续与限制

额外当前映射对pre不是免费；post可复用已有当前分支，但其aligned-input增强仍多于单前向+缓存输出warp后处理。本实验共享计算耗时不能当部署成本，未做手机测试。图已查看，表/逐片/全部gate向量/body哈希/回放/过程/代码与报告分别小步提交。

接续R25将固定既有四native/双seed终点，比较原teacher、同GT估计flow共同接受域的teacher、同共同域的GT估计flow；current替代和R14经典后平均作为控制。先分开mask收缩与flow选择变化，不称GT flow为真运动/EPE或可部署信息。由于评价时序本来用GT估计flow，不能只看其时间指标；PSNR/SSIM/edge需同时核查。若仍无一致质量恢复，不能继续把失败泛归因于对应，需回到训练/域与统计表示。原论文目标active，最终保留素材未读。
