# 0019｜优化基线与新增开发集

创建：2026-11-11T18:37:19.661834+08:00；作者：Codex  (sqs_A100)；原因：R8优化混杂后，完成固定预算单帧学习率控制及未参与训练的开发片段评价。

普通单帧基线此前存在明显优化空间。只改变学习率、不增加参数，1000步即获得远大于早期小模块的质量增益。因此后续结构候选必须在强优化条件下重新作历史替换、空间容量和后处理比较。早期负结果仍是对应低学习率短微调的有效观察，不能推广为整个时域结构族无效。

## 新数据及训练

在读取新像素前，按官方TRAIN剩余19个同名配对目录等距索引0/6/12/18，固定video_15/47/91/121。各前16共同PNG，共128文件、337539503字节；逐文件LFS SHA/bytes验证，与既有R3/R4/R4b无精确文件重叠。它们划为本项目dev，不进入梯度训练；hash不证明物理场景独立，白天ND衰减不代表夜景。旧六test多次探索，未用官方test三段与Kodak13–24继续保留。

保持R5十二实拍+合成的每步当前/GT身份、4075参数、双seed、固定最终1000更新。新增full1e-4、full1e-3、首个Conv5权重+bias1e-3其余1e-5，共6次6000步；Adam wd0，Charbonnier .001，全主干统一clip1。R8 copy的两个组分开clip，不能假称优化轨迹精确等价。六次初始任务/梯度范数差均0，60份checkpoint SHA通过，无评价挑checkpoint。
