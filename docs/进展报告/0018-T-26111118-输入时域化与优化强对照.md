# 0018｜输入时域化与优化强对照

创建：2026-11-11T18:25:04.346271+08:00；作者：Codex  (sqs_A100)；原因：0017后完成原始双帧首层学习与同参数单帧控制。

当前没有确定视频结构。第八轮发现：即使分支可以完全折叠回原单帧卷积，快学习率也带来显著PSNR增益；双帧结果必须进一步扣除优化因素。下一轮优先核验基线优化与开发集，暂不扩展固定特征混合模块。

## 实验与证据

保持MobileIE原head/body平方、attention与tail，仅在首个Conv5后、PReLU前加零初始化无bias Conv5(3→12)，900参数。5模式×2seed×1000更新，共10000步：spatial_copy使用当前输入；spatial_detail使用当前减局部平均；concat使用前帧；delta使用前帧减当前；delta_aug另对历史作10%自身/10%错配/80%真实增强。主干1e-5、辅助1e-3，分别clip1，任务Charbonnier；当前/GT逐步与R5 plain一致。初始任务和主干梯度范数差均0。

spatial_copy与原首层同输入、同kernel，可数学折叠，不增加单帧函数族；concat换成自身历史也可折叠；delta自身历史为零。全部双帧权重因此另外评价current历史，以隔离真正的过去输入贡献。训练4975参数，plain4075；未完成训练权重FP32折叠/手机速度核验，不能据数学等价报告部署收益。

38个旧探索条件、2seed，raw/共同half01后处理、输入reset开关，完成2736行。以下无reset、raw均值：

copy在实拍+.469dB、旧合成+1.387dB；不是时域收益，也非统一画质/稳定性改善。concat实际历史实拍反而比current低.0344dB且时间误差更大；delta的实拍时间误差小降伴随PSNR下降，合成PSNR小升伴随时间误差上升。增强历史没有解决跨域权衡。

共同half01仍是重要强参考，例如plain实拍时间误差2.42026→2.27994，旧合成15.86217→14.08015；不能遗漏其motion/teacher成本。事件cut全序列concat的causal/current PSNR20.47343/20.27411，但时间误差16.65275/16.38045；light-step21.36311/21.25790，时间误差16.81504/16.44453。事件PSNR单指标提升仍不能宣布时域稳定成功，固定reset及frame12结果完整保留。

## 范围、核查与决策

100份周期checkpoint SHA通过；每步当前/GT身份与R5匹配。4000个增强历史决定3204真实、428错配、368自身。plain旧checkpoint重放最大指标差7.11e-15，4项head机制测试已通过。四项GPU任务成功，仅2/3卡、并发峰值2，175启动源码哈希匹配，共1331.488进程GPU秒包含CPU工作；不是内核时间。预检和本地锁不等于全局预约。

本批仍是6段ND实拍、2个旧合成源及6张Kodak探索图的事件重复，不能把2736行当独立视频。未代表自然夜景，未达到原模型完整训练预算，也未复现强视频模型。

接下来：以相同1000更新、固定最终checkpoint，限量比较普通主干更高学习率和首层分组学习率；先登记再运行。从未使用的官方train配对片段划开发集，未用test与Kodak13–24继续保留。后续分开核验历史对应几何、原生尺度/降采样噪声及优化条件；没有证据时不把低学习率短微调的失败推广到整个结构族。
