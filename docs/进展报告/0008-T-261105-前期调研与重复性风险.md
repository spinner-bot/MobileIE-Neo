## 2. 关键结论

### 2.1 没有直接重复

- S2/OpenAlex/Crossref 的引用列表中，**没有 “MobileIE + 视频时序一致性/闪烁” 的直接工作**；
- 唯一明确的视频低光增强引用是 **AnyMod-LLVE**（ICML 2026，多模态重模型），与 4K 参数单图网络扩展不构成重复；
- 33 条引用中，检测/医学/分割等无关工作约 18 条，占大多数。

### 2.2 同组接续（5 篇，全部单图）

| 工作 | 与 MobileIE 关系 | 任务 |
| --- | --- | --- |
| YUV L3IE（arXiv 2601.17349） | 同第一作者 | 单图轻量低光 |
| LiteIE（ESWA 2025） | Hailong Yan 参与 | 单图无监督；58 参数、4K 30 FPS |
| IGDNet（IEEE TAI 2025） | 同第一作者 | 单图零样本 |
| FGDPA（arXiv 2606.30314） | Le Zhang/Ao Li/Ce Zhu | 实时水下；4.23K 参数、600+ FPS |
| DRNet（IEEE TMM 2026） | Ao Li 等 | all-in-one 图像复原；动态重参数化 |

→ 它们占据“轻量结构/重参数化/单图画质”的生态位，**没有占据视频时序一致性**。

### 2.3 TeleAI 线索未能证实

- S2/OpenAlex/Crossref 引用中无 TeleAI 署名；
- TeleAI 2026 中文综述《极端环境图像退化、处理与应用研究综述》的 85 条公开参考文献中无 MobileIE；
- TeleAI 的 ReDDiT、Lumina-OmniLV、水下生成式复原论文中均未检索到 MobileIE；
- Web 检索 `"MobileIE" "TeleAI"` / `"MobileIE" "China Telecom"` 无关联结果。

→ 可能存在未被索引的中文期刊/内部工作；需导师提供确切出处，或用 Google Scholar / IEEE Cited By / 知网复核。

### 2.4 新颖性定位（建议）

1. **C1（主）**：极轻量单图增强网络的训练期时序一致性，推理零开销；
2. **C2（差异化）**：可见性加权（JND/平坦区/时间高频），依据 3 号工作的测量；
3. **C3（加分）**：量化的时序稳定性（INT8/TFLite），暂无 4K 参数 RGB LLIE 的先例；
4. **C4（支撑）**：逐模块消融，解释闪烁来源。

最大风险仍是“后处理够用”：EMA/光流 EMA 已降 73%，必须用快速运动、无拖影、低延迟证明训练侧必要性。

## 3. 结论

- 选题空白成立，可以继续；
- 但“只加一个 temporal loss”大概率会被认为增量，需要 C2/C3/C4 至少两项支撑；
- 下一步的关键不是继续读论文，而是拿到真实视频 + 服务器后跑实验，用数据支撑差异化。
