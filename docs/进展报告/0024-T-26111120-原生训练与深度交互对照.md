# 0024｜原生训练与深度交互对照

创建：2026-11-11T20:21:00.148883+08:00；作者：Codex  (sqs_A100)；原因：汇总固定训练尺度、深度及同容量/历史控制，决定下一阶段切入点。

原生尺度训练与足够更新次数明显影响画质和波动；真实历史仍未形成足够独立收益。首层对齐拼接方向继续降优先级，后续转向具有空间层级和更大有效感受野的时间聚合诊断，同时补跨数据源。尚无最终方法或创新结论。

## 成对设计与完整性

原12训练片段、相同当前帧/GT和合成流，plain4075、copy4975、aligned concat4975参数，双seed，强Adam1e-3/global clip1/Charbonnier .001。native随机320×180原生ROI从官方权重训练4000；resize从既有1000完整模型和Adam矩延续到4000。总42000新更新，固定1000/4000全部评价，非按dev选checkpoint。原生与缩小同时改变噪声、视野内容、运动像素和GAP上下文，不作纯噪声因果归因。

12段训练身份和后3000任务流匹配；48 checkpoint SHA/finite/参数/Adam步数与trace前缀均通过。42000包含24000 native新训练及18000 resize延续，6个旧1000 checkpoint仅复用。第一轮评价在0指标行时遇list.any类型错误，修复契约后新guard重试，失败资料全部保留。

46既有探索条件新增4416逻辑行，实际1248推理序列、2928指标计算、1488精确alias；复用1472旧1000行，共5888。逐帧alias和首帧差0，46不代表独立视频，原生与缩小dev共享4片。

以下raw、无reset、双seed均值；时间为GT残差时间误差，越低越好。

原生plain在原生dev由1000步23.65132/.90562/3.40658变为4000步27.17326/.91624/3.45319：PSNR提高不意味着时序误差自动降低。resize plain原生dev SSIM由.89606降到.85921，时间4.05308升到4.90060；缩小dev SSIM却由.89835升到.93596。训练分布与评估尺度交互不能忽略。

同一aligned权重换current-only，native4000原生dev为26.50352/.91568/3.29638，真实历史仅+.00058dB、+.00050 SSIM、时间-.04460；旧ND PSNR-.00146，缩小dev-.00106。resize4000真实历史原生dev+.00352dB、时间-.07694。合成历史稍大（native+.03602dB/时间-.23914），仍不能把整体训练增益认作时间信息收益。空间copy在原生dev反而比aligned高约.736dB。全部逐片、事件、half01与reset结果保留，不只展示均值有利项。
