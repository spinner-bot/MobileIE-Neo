## 1. 任务背景

导师在 2026-11-08 的会议中交代：论文里有一个叫 AI Benchmark 的手机端测试工具，需要尽快在安卓手机上跑起来并演示，用于项目申报的现场考察，“不用做研究，原文怎么弄就怎么弄”。

核对论文、官方 README 与代码后确认：

- 论文的手机部分**只用于测推理延迟**（Snapdragon 8 Gen 3，0.895 ms / 1100 FPS）；
- 官方 README 的手机流程是 `lolv1.tflite` → AI Benchmark → 推理速度；
- 仓库没有 Android App，也没有可视化 demo 代码；
- 论文效果图来自数据集 + GPU，不是手机实时输出。

因此“直接复现论文手机做法”只能得到延迟，无法展示增强效果。经与用户确认，采用 **B 方案**：手机跑 AI Benchmark 测速，电脑复用官方 TFLite 脚本生成前后对比图，现场组合展示。

## 3. 关键结论

### 3.1 模型可直接用于 AI Benchmark

解析 `MobileIE/pretrain/lolv1.tflite` 得到：

| 项 | 值 |
| --- | --- |
| 大小 | 23 KB |
| 输入 | `serving_default_input_1:0`，固定 1×400×600×3，FLOAT32 |
| 输出 | `StatefulPartitionedCall:0`，1×400×600×3，FLOAT32 |
| 算子 | 23 个标准算子：CONV_2D ×6、MUL ×9、ADD ×2、LOGISTIC ×2、PAD/MEAN/PRELU/REDUCE_MAX 各 1 |
| 自定义算子 | 无 |

单输入、单输出、固定 4D 形状、无自定义 op，满足 AI Benchmark Custom Model 的加载条件。

### 3.2 AI Benchmark 只给速度，不给画面

- AI Benchmark v4（2020-05）起支持 PRO Mode 加载自定义 TFLite 模型；
- v7.0.0（2026-10）仍保留该功能，支持 CPU/XNNPACK、NNAPI、GPU、QNN/Hexagon、Neuron、ENN 等后端；
- 官方定位是跑分，自定义模型只输出延迟与错误日志，不显示输出图像；
- 未找到可加载任意图生图 TFLite 模型的现成免代码 App（Google AI Edge Gallery、ML Bench、TensorFlow 官方示例均不满足）。

→ 效果展示只能复用官方 TFLite 脚本，或另行开发（本次不采用）。

### 3.3 当前环境缺口

- 研究虚拟环境 `F:\dev-tools\python-envs\MobileIE-Neo` **没有 TensorFlow / tflite_runtime**；
- 不建议直接在该环境安装 TensorFlow（可能改动 numpy 版本，影响 3/4 号工作）；
- 计划新建独立演示环境 `F:\dev-tools\python-envs\MobileIE-Demo`，安装 `tensorflow-cpu`、`pillow`、`numpy`。

## 4. P0 执行结果（2026-11-08 补记）

### 4.1 环境

| 方案 | 结果 |
| --- | --- |
| `tensorflow-cpu==2.21.0` | 失败：`_pywrap_tensorflow_common.dll INITIALIZATION FAILED (0x45A)` |
| `tensorflow-cpu==2.20.0` | 失败：`_pywrap_tensorflow_internal` 动态链接库初始化失败 |
| `ai-edge-litert==2.3.0` | 可用；默认 XNNPACK delegate 在 `allocate_tensors()` 时段错误，关闭后正常 |

最终在独立环境 `F:\dev-tools\python-envs\MobileIE-Demo` 中使用 **ai-edge-litert + `BUILTIN_WITHOUT_DEFAULT_DELEGATES`**，由 `run_official_tflite.py` 自动注入兼容层，官方脚本未改动。

### 4.2 效果验证

- 官方 `test_TFLite_RGB.py` 跑完 LOLv1 eval15 全部 15 张；
- **PSNR 均值 23.619 dB**（min 15.650 / max 27.618），与论文报告的 23.62 dB 一致；
- 生成 `results/compare_lol_eval15/`（15 张对比图）与 `results/compare_sample/`（仓库样例）；
- HTML 报告已内嵌样例对比图，可离线查看。

### 4.3 结论

电脑侧效果链路已跑通，且数值与论文对齐，B 方案可行。剩余工作集中在手机测速与现场素材。
