# 0036｜同接受域对应选择与训练目标转向

创建：2026-11-11T23:39:22.687944+08:00；作者：Codex  (sqs_A100)；原因：R24读出节点不能统一补回主差距，固定同接受域诊断mask与flow选择，依据证据转向目标/优化强对照。

替换为缓存GT估计流并未恢复主要质量差。共同接受域内PSNR均值仅+.005至+.022dB，不能解释约1dB的聚合模型差距；这不是否定所有对应方法，只降低继续泛归因于当前flow的优先级。R26已预注册并启动三映射×Charb/MSE的完整目标/优化对照，不增加结构模块。

## 完整预算与公平解释

R21四模式及R14 output-warp.5、双seed4000、四native全部16帧，每个current/default teacher/common teacher/common reference，共160配置/2560帧。80正式序列/1280帧重放最大差0，80新增诊断配置；60帧对两common接受像素集合全部相同。首帧最大差0，MSE闭合8.33e-16、正式PSNR恒等式7.11e-15dB。160真实指标计算、0alias，实际模型序列pass136、backbone forward2688帧，仅为共享实验计数。CPU193.415s、RSS约1.16GiB、CUDA未初始化；零新训练/测试素材。

common为teacher与reference各自FB有效区及gather bounds交集。default→common teacher分离mask收缩，common teacher→common reference为同接受域下flow选择。两者均接触GT估计信息，不是可部署控制。R14后处理alias依据增强输出warp字节，而非低光输入字节；本轮没有相同完整输出alias。

## 决策与下一轮

R19/R21b说明独立静态信息可用；R21动态固定聚合训练不稳定胜出；R23全局误差分解、R24gate及本轮flow选择均未给出足够恢复。停止扩大任意模块/flow参数网格，转向监督目标与优化的配对强控制：plain/pre.5/post.5各Charb/MSE、双seed4000共48k更新，全部原R14任务/ROI不变，六独立模型共享每step历史准备。Charb组重训并逐tensor核查旧模型/Adam，固定1000/4000全部评价，MSEplain+经典后处理是必要强参考。

MSE原尺度改变梯度/clip/Adam耦合，因此不是纯方向实验，不用dev结果缩放。首步记录匹配输出、梯度范数比/cosine；逐步记录global/centered MSE。仅目标/优化强对照，常见MSE/平均不当创新。GPU1首次被别人占用时guard拒绝，seed1在新两次预检空闲GPU3运行，seed0改GPU0重新预检，最多同组两卡；启动前日志目录失误0更新单独保留。初始Charb日志已见旧task差0，仍不能宣称最终模型重放或质量提升。
