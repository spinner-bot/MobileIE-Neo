# 0034｜全局RGB偏差与空间误差分解

创建：2026-11-11T23:08:14.927234+08:00；作者：Codex  (sqs_A100)；原因：R21动态聚合质量下降且固定帧见色调差异，先用已有预测区分全局与空间项，不新增推理或训练。

固定seed0的四native片段中，真实历史相对current替代的平均MSE增量主要落在全局RGB均值误差项，但片段间异质性明显。这是精确误差分解，尚未定位到网络门控或证明新的修正方法。下一步固定权重检验全局通道读出是否介导变化，不直接增加模块/损失网格。

## 范围、口径和失败

只读R21既有52数组（缩图/编码前FP32原值），四片×16帧、seed0/4000、3强参考+4候选current/causal，共44序列/704帧、64比较；52 SHA通过，零新训练/推理/测试数据。原GT和指标不变。首轮错误假定PSNR裁边8，在正式逐帧重放门槛中失败，0统计行完成；实际正式PSNR全帧，裁边8只用于动态时序有效区，静态矩另有margin8。先保留失败、修协议空间范围再重跑，全程未放宽容差。详见新[指标口径](../../research/4.temporal-consistency/docs/metric-spatial-scope.md)。

最终全帧PSNR回放最大7.11e-15dB（门槛1e-8），MSE恒等式最大8.17e-16（门槛1e-12）。CPU8.332s、RSS约.53GiB、CUDA未初始化。主图PNG已查看，PDF/全部帧/序列/比较均分别提交。

## 精确分解与实际历史变化

每帧e=prediction-GT、空间RGB均值μ，MSE=mean(μ²)+mean((e-μ)²)。全局项再分common-channel mean(μ)²及opponent-channel mean((μ-mean(μ))²)，这不是感知亮度/色度。每片另分持续全局偏差与其时间波动，后者不能当主观闪烁或替代原GT补偿时序指标。

下表causal减current，四片均值，单位为8-bit RGB平方；正值更大误差。

fixed pre/post中心化空间误差在均值上反而改善，全局偏差增加抵消了它；因此global excess/total excess可>1，不应截为“贡献百分比”。learn两组的全局项亦占主要均值增量，但不是每片同一机制：video47的learnhalf global/centered差为+55.81275/+.45588；video15的post为-3.53745/+11.38705，方向与均值不同。所有逐片/逐帧通道均值保留。

## 边界和后续

这里只有协议固定seed0，不是双seed普遍性结论。MSE均值会强调高误差片段，而平均PSNR先取log，排名可不同；不能用本轮MSE聚合推翻报告0033的双seed平均PSNR。相对R14单帧，各候选的全局/中心化项也有相互抵消，不能声称全部质量损失来自颜色。GT均值移除只是数学分析，没有生成校正算法或新性能。

R23并未因果定位FST/HDPA，R22也未证明全网误差来源。下一步用全部四模式、双seed、四native固定终点，仅在冻结网络中令实际历史分支使用同网络当前输入产生的全局att通道门控，其他body/空间门控公式不变；与原current/causal及强后参考严格回放，记录质量、时序与全局/空间项。该干预需要额外当前分支，仅作为机制探针，不宣称部署效率或创新。若无一致作用，降低该假设优先级，再考虑对应上限而非泛化猜测。最终保留素材未读，论文目标active。
