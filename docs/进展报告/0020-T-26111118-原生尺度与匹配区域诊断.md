# 0020｜原生尺度与匹配区域诊断

创建：2026-11-11T18:44:31.403938+08:00；作者：Codex  (sqs_A100)；原因：R9后核验降采样之外的原生开发数据及输入平滑权衡。

粗输入平滑降低时间误差，却明显损失画质，不能把更小波动直接当成功去闪烁。强单帧优化在原生crop仍有效，同时存在失败片段。下一步需要在更强优化条件和同容量空间对照下检验对齐历史。

四段R9项目dev各16帧，读取结果前固定中心[x704:1216,y396:684]512×288区域。native保持原样；smooth只将低光AREA128×72再LINEAR回512×288，GT/reference原样不动；full-area整图AREA512×288。解码后FP32制备，不添加量化。平滑同时改变细节和噪声；full-area另改变FOV、内容和全局池化上下文，都不能当纯噪声干预。

全部11权重：官方、R5plain双seed、R8copy双seed、R9三种优化各双seed。无新增训练，不按R9结果挑权重。四片×三制备×十一权重×raw/half01=264行。GT估计reference不是运动真值；native/smooth四片GT、reference_flow/mask逐数组相同，teacher重复最大像素差0。

原生crop微调为双seed均值：

full1e-3相对plain原生平均PSNR+6.072dB，但video91为19.58973低于plain20.61142，其SSIM和时间误差也更差。其余三片较大增益不能代替统一可靠性。

同GT下full1e-3粗平滑：PSNR22.07285（-3.04469dB）、SSIM.82185（-.07421）、时间误差3.22595（-.82713）、edge2.21332（+.52574）。六类权重配对均值PSNR/SSIM全部下降、时间误差全部下降。half01在原生输入上保留更多质量，是必要强参考；额外teacher/motion成本不能省略。

输入HH-MAD包含纹理，不是真实传感器噪声SD；video15 full-area代理还高于native，说明不同FOV纹理足以改变该值。原生full1e-3时间误差4.05308与full-area2.37088不可直接解释为纯噪声放大量。

固定frame0四片×三制备，每图输入/GT及全部11权重，共12图；检查全部四native图、平滑例和汇总图，可见残余颗粒及亮度/颜色差异。单帧不能判断视频观感，不作挑片证明。全部像素cache有SHA，逐片逐帧指标保留。

两GPU作业成功，仅3卡并发1，199启动源码哈希匹配，共264.296进程GPU秒含CPU；预检不是全局预约。源码、结果、统计、图、过程、报告分别小步提交，无push或merge。
