## 4. 目前真正未解决的问题

**历史是否提供了超出空间增强和平滑的独立有效信息。** 多个候选的空间均值有改善，但历史开关对照收益很小，或者以明显画质损失换时序。下一个有价值的方法必须回答历史贡献来自哪里，不能只再加一个状态模块。运动错配、噪声污染、表征不足、监督偏差与训练域差异都是可能因素，现有结果没有确定唯一原因。

**怎样在运动和细节变化中选择可用历史。** 直接平滑会混入跨帧变化；传统运动补偿仍是强参照，但处理和状态有费用。未来观察显示信息可能有用，却引入等待，现有固定未来算子也未过完整门。需要检验的应是具体的信息或结构假设，而不是继续同一平滑、gate、loss参数网格。

**如何使质量、时序与部署费用共同成立。** 没有新增卷积不代表免费：I1-S全层/输出的解析FP32保留状态约427/24MiB，还需EMA、复制和历史访问。它们不是峰值RAM，也没有手机时延结论。原4075参数和零额外推理是有吸引力的参考，不是已证明不可放宽的唯一路径。允许未来或更多容量的方案必须明列等待、参数、完整流水线时间和内存。

**创新与泛化能否支撑论文。** EMA、特征传播、递归状态、运动补偿、固定时滞、蒸馏等都有先例，组合本身不自动新颖。已有重复DEV、REDS外部开发与无GT手机视频有价值，但还没有本分支成功候选在自然动态夜间、实际手机与独立最终上的证据。不能把尚无成功候选写成完全没有外部比较，也不能把反复使用的开发集写成独立测试。

若后续恢复研究，建议按以下顺序设有限目标；这些是下一阶段建议，并非已经登记或启动的实验：

1. 基于本轮完整证据，选定一个能与“当前帧增强＋经典post”清楚区分的核心假设，说明为何应存在新的可用信息或可部署优势；不继续扩失败模块排列。
2. 先固定空间质量保护、同权重历史对照、传统强参照和实际成本范围；用有限实验判断假设是否值得正式投入。空间改善、时间改善与内部机制结论分别举证，全部局部止损继续有效。
3. 只有候选通过开发资格，才登记完整流水线费用、感知与外部自然视频复评；方法和协议冻结后再启用独立最终。手机需要实际测量，不能从服务器速度或MAC外推。

当前没有已确定的下一原创架构，也不承诺某一尚未验证的路线一定有效。阶段目标应由“多做实验”收紧为“确立一个可被推翻、也可能形成论文主贡献的假设”；若无法形成方法优势，需要重新评估诊断型论文能否有足够普遍性，而不是把诊断数量当论文成熟度。
