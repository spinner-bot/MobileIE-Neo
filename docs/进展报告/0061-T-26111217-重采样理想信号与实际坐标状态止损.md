# 0061｜重采样理想信号与实际坐标状态止损

创建：2026-11-12T17:10:16.427878+08:00；作者：Codex  (sqs_A100)。原因：以廉价独立机制控制和实际增强输出对照检验一个新切入点，完整收口后按门槛决定，不扩R45提示网格。论文长期目标仍active。

## 已完成工作

先核对[重采样与运动累积先例](../../research/5.prior-art-survey/docs/35-resampling-and-coordinate-state-boundaries.md)，再分别登记oracle与实际流协议。CVPR2024已有双线性损失高频及隐式重采样，Meshflow已有相邻运动累积与对齐融合；泛用坐标/滤波不能作为首创。

R46第一阶段只用解析纹理、三种已知运动和固定噪声，五alpha、固定K8。150正式输出/75K1诊断回放/127检查，17.892秒正常结束，零真实/DEV像素。主要α=.75分数运动，晚段中央MSE比clean .482196、四noisy均值.507411，机制门槛通过；全部alpha保留，不将clean重复拷贝当独立样本。这一结果只说明特定控制中重采样损失可减少。

据此另行登记实际流K8/α=.5及same_mask控制。40项人工检查通过后，复用R44两个最终square_MSE raw缓存，CPU60新质量行/2688逐帧行完成，耗时272.923/248.979秒。没有训练/CNN/GPU/新保留像素；原ordinary重算与R45 fixed .5四指标差0。

## 实际结论与止损

候选对普通递归合成画质+.1508/+.1814dB，配对ND−.0102/+.0125dB；但四项时间比为1.03487/1.03012/1.02891/1.02560，全部变差。相同拒绝mask的普通递归画质更高且时间更低：候选对它合成−.03093/−.03000dB、ND−.01312/−.01003dB，时间比均约1.0013–1.0015。八个注册时间门槛全部失败，ND seed0还被fixed .5支配。

因此增加拒绝已解释相对ordinary的合成空间变化，不能说少重采样带来实际独立收益。累计有效性使SYN接受比例约91.8%→77.5%、ND约94.5%→83.3–83.6%，必须保留同mask对照。根据[决定](../../research/4.temporal-consistency/docs/exploration-r46-decision.md)，停止本K8双线性坐标状态的K/alpha/插值/阈值/追加seed网格，不做成本追分。理想正信号不等于真实视频成功，也不普遍排除其它表示。

真实原型保留原生双向坐标和mask，持久历史解析存储42HW bytes，比普通24HW多75%；不是实测峰值或手机成本。既无质量—时间胜出，不再为它压缩坐标。空间骨干与R45提示均未改动，不用新名字延续被冻结路线。
