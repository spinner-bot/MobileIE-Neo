# 0022｜已发表去噪对照与原生窗口

创建：2026-11-11T19:14:19.038547+08:00；作者：Codex  (sqs_A100)；原因：R11后补充实际已发表视频去噪参考，区分空间去噪、真实时间信息、尺度与延迟。

FastDVDnet在原生ND开发裁剪上建立了小但可复验的真实五帧信息窗口，缩小后的实拍却明显受损。这提供了比自设模块更强的参考，也说明不能把原生/缩小域混合为一个去噪结论。方法有2479096参数且需要两帧未来，不能直接充当同预算零未来轻模型。

## 接入与预算

官方commit c8fdf6182a0340e89dd18f5df25b47337cbede6f，MIT许可；模型/推理源码原字节vendor，Git对象/bytes核验。固定clipped-AWGN权重9971551字节，Git blob413d19765b821355e31906ca16332006d8d3a4eb，另有SHA256。官方测试脚本会新增噪声，适配器仅调用网络/推理函数，不加噪声、不微调。

固定R9full1e-3两seed作为增强底座，sigma5/15/30全部报告；window五帧中心、window_segmented按输入事件划段后reflect、five_current五份当前帧。window两帧未来，分段也不变成零未来算法；five_current是同网络去除时间信息的控制，不是独立发表的单帧模型。

新增3项路由检查通过。训练Kodak01固定8帧clipped AWGN25 smoke：PSNR20.30510→29.77754，与官方归一化输出最大差0；预设1e-6及至少1dB门槛通过。这只说明接入/归一化正确，不代表低光泛化。

46条件×2seed×10调用=920行；92底座raw重放最大指标差0。两个seed的context索引相同，最多未来2帧，five_current为0，分段没有跨事件。固定4dev的native/resize仍共享物理源；旧test反复探索，未用最终素材继续保留。

## 成本和接续

共享A100串行GPU阶段每帧中位：480270底座.6147ms、去噪9.7322ms；512288底座.6470ms、去噪10.6901ms。包括Python/分配，排除加载/传输/指标/完整CPU流程，不是手机测试，也不能与R4含传输/光流的完整34.4ms直接求比。两帧等待另于处理耗时，30fps输入对应约66.7ms未来等待；参数约为原4075模型的608倍。

三项GPU进程全部成功，仅2/3并发2，225启动源码哈希匹配，468.153进程GPU秒含CPU。图、每文件结果、过程和报告分别提交。原高斯预训练与当前泊松/JPEG/ND/增强噪声不匹配，结果为迁移对照，不是原DAVIS基准复现，也尚未补齐低光视频论文强模型。

R13继续深查pair训练50%self历史：保留当前监督、GT与强优化，仅给first任务帧补因果前置历史。空间1000步重放每步损失/梯度/aux norm及最终权重差0，时域训练进行中。它是待检验原因，普通burn-in不是新颖性。论文目标持续进行，尚未确定正式方法。
