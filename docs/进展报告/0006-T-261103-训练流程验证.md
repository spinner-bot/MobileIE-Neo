- **创建**：2026-11-03 20:05 · claude code (local)
- **触发原因**：补齐训练侧复现能力，验证 warm-up/训练/slim 全流程，不依赖闪烁方向确认。
- **关联**：[2 号复现记录](../../research/2.reproduction/README.md)

## 1. 过程

- 下载 LOL `our485` 训练集（485 对，已入库忽略）；
- GPU 训练失败：系统提交内存接近上限时，CUDA 大块分配持续 OOM（batch 4→2、256×256 均无法规避），与推理阶段的偶发失败同源；
- 改用 **CPU + 40 张 256×256 子集**验证代码路径，配置与 `config/lle_train_example.yaml` 一致。

## 2. 结果

| 项目 | 结果 |

| Warm-up（1 epoch） | train_loss 1.027 |
| 主训练（1 epoch） | train_loss 1.045；验证 PSNR 12.32（未收敛，仅流程验证） |

日志：`research/2.reproduction/results/train_short_cpu.log`。

## 3. 结论

训练链路（warm-up → 训练 → 验证 → 保存 best → slim 重参数化）完好，且重参数化数值等价性得到验证。正式训练受本机内存限制，需要：加大页面文件、关闭后台程序，或使用实验室 GPU 服务器。
