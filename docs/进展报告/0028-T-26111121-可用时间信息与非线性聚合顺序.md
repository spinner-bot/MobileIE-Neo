# 0028｜可用时间信息与非线性聚合顺序

创建：2026-11-11T21:42:16.205919+08:00；作者：Codex  (sqs_A100)；原因：在已知无运动对应下分离时间信息可用性与模型利用，再补强后处理对照。

当前模型在受控静态条件下没有充分利用可用时间信息。传统两观测平均可带来约1dB，而同权重真实历史只带来百分之一dB量级；但增强后平均也很强，前置平均没有统一独立优势。下一步先比较动态视频中的对齐/聚合顺序，不把经典平均或算子顺序当作创新。

## 固定实验与核查

仅训练Kodak01/06固定128×128 patch；photon20/80、JPEG off/on、rho0/.9，16条件各64独立观测对。Poisson thinning及条件Gaussian使current跨rho逐像素完全一致，JPEG后相关性另测。静态已知零运动、一过去零未来，无GTflow部署，不读取最终保留素材。

九权重：original、R14 native plain双seed4000、R16 spatial/raw/aligned各双seed4000；FP32/batch8，所有路径同batch。current/preaverage及时间模型真实history共352RGB统计行，MSE=条件均值偏差²+draw方差FP64闭合；输出先记clipping再clamp，margin8。64draw不是64独立场景，也不是实际视频闪烁评价。

四CPU fixture通过；16 cache/9 checkpoint SHA核验；72跨rho current输出精确。独立噪声下输入平均方差比.4980–.5007；rho.9无JPEG实际相关.8986–.8998、平均方差比约.95，JPEG后实际相关.6920–.7217、平均方差比.8439–.8607。不能用预设rho直接代替观测噪声相关。

无JPEG独立噪声下，R14前平均输出方差比约.534，而学到的raw历史方差比约.992、aligned约.975。对应虽完美，模型仍利用弱，运动误差不是该静态现象的必要解释。这不能直接证明真实运动噪声的最优融合方式。

## 必要的聚合顺序反证

对同16 cache/9权重，补clip各帧后平均、raw输出先平均再clip两种强控制，新增288行。288个current/preaverage source输出逐像素重放精确，另144项整个网络的pre/post raw gap矩分解闭合。总640含352复用，不作独立视频计数。

R14独立无JPEG前平均比clip-first后平均高约.0928dB，JPEG条件后平均反高约.2278dB；高相关条件差距更小。original在两个编码条件下也出现顺序偏好翻转。均值偏差与方差随非线性顺序变化；gap包括head/body、门控、激活等完整网络，不能单独归因FST。四种预设条件和全部模型均报告，不只展示有利项。
