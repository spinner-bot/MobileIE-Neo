# 0032｜聚合训练后的静态信息利用强对照

创建：2026-11-11T22:49:35.653308+08:00；作者：Codex  (sqs_A100)；原因：R21动态评价仍运行，固定既有零运动缓存与全部终点，区分历史利用、映射变化和经典强参考。

聚合训练能在静态独立噪声中产生明确历史利用，但可学习alpha仍可能输给普通后平均；“依赖历史”和“超越强基线”必须分开。此结论仅限两训练图的完美对应合成观测，不是视频结果或新方法。

## 控制与完整性

先单独提交R21b协议，随后实现/运行。复用R19固定16条件×64对观测，Kodak训练01/06、128方ROI、photons20/80、rho0/.9、JPEG70开关；零新像素/训练。R21四模式双seed4000全部current/causal，共256行；同CPU重新计算R14 plain双seed的current/preaverage/两种postaverage，共128行。全384行/10权重/16缓存SHA通过；80次current跨rho输出SHA完全一致，FP64总体MSE=bias²+draw variance最大闭合残差1.52e-18。CPU FP32/batch8/两Torch线程，134.209s，峰值RSS约.77GiB，CUDA未初始化。

## 强参考改变判断

相对未经聚合训练的R14原始输出后平均，fixed pre在独立无JPEG/有JPEG有+.67773/+.17697dB，fixed post为+.32071/+.20189dB；相关JPEG时两者分别-.16794/-.10396dB。learn0在四组均低于该经典参考，约-.36至-.54dB；learn.5亦全负，约-.35至-.57dB。全条件/photons/图/seed配对结果保留，不只报独立噪声正收益。

learn0/learn.5 current替代本身在独立无JPEG平均较R14单帧低约.553/.556dB，历史收益抵消一部分映射变化；这不等于训练失败的单一因果解释，因为替代current也改变输入分布。两种alpha最终接近.4不代表完整网络或质量相同。静态训练适配收益不能外推为运动场景收益，也不能把差异唯一归因于对齐。
