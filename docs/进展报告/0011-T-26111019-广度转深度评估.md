# 前期探索的广度与深度：阶段判断

- 创建：2026-11-10 19:44 +08:00 · Codex  (sqs_A100)
- 触发：用户要求判断广度是否已充分展开，以及是否应转向深度探索。
- 依据：[0010首轮报告](0010-T-26111018-首轮调研与预实验.md)及其逐序列CSV；本次未运行新实验。

## 判断

广度尚未穷尽，也没有测量证据能证明所有新增方向的边际收益已经严重下降。但已有证据足以停止继续堆叠相近的推理期滤波/EMA组合，转为以机制验证和受控训练为主的定向深挖，保留少量关键对照补齐。

这一转向是基于当前最需要回答的问题，而非基于“方法已找全”。仍没有确定最终模型或组合。

## 证据与覆盖边界

- 本轮891条方法—序列评估来自3个已有场景、54种不同输入条件，重复使用同类纯平移合成设置。
- 已覆盖简单空间去噪、时域平滑、低光光流、真值对齐、全局门控状态及部分组合。
- 尚未覆盖受控训练比较、实质时空结构改造、真实视频/遮挡、强传统视频去噪和较强学习型对照；部分相关论文只核查了摘要。
- 因而，现有宽度主要是同一受控设置中的处理方法宽度，不是数据、结构和训练三方面均已充分覆盖。

将门控EMA与flow EMA组合，相对单用flow EMA的固定光照噪声序列PSNR增益，按场景平均为：

| 场景 | 固定光照增益 | 光照突变增益 |
| --- | ---: | ---: |
| source | +0.0251 dB | -0.6475 dB |
| lol1 | +1.1261 dB | -0.2917 dB |
| lol22 | -0.5324 dB | -1.4464 dB |

整体均值不能说明该组合普遍有效，也不足以将全局状态确定为主贡献。光照反例和真值/估计对齐差距已经给出适合深入检验的具体问题。

## 后续研究组织

主要深挖对象：噪声传播、增强映射与时间冗余如何共同决定视频稳定性。全局状态、稳健特征变换及可靠性对齐保留为候选机制，不预先指定唯一根因或最终方案。

1. 先补必要的数据宽度：独立场景、小规模真实视频及至少一种非纯平移/光照变化设置，用于检验已有现象是否成立。
2. 针对代表性失败做帧级诊断和控制变量干预，解释门控状态何时有益、何时有害；区分平滑响应、亮度误差、噪声与对应关系误差。
3. 推进同预算受控训练：原模型、普通去噪增广、基础时序损失，以及少量有机制依据的结构候选；先分离训练收益，再判断结构贡献和组合交互。
4. 精读与候选直接相关的少数工作，并补一个强传统或学习型对照，避免简单基线过弱。

暂缓继续罗列大量模块、重复扫描相似EMA系数、把更多结果都堆在同3张图上，以及未经机制筛选就全面重训所有变体。

## 深挖的阶段出口

- 若独立场景上现象不成立，或普通去噪训练已解释收益，调整假设，而非继续包装同一模块。
- 若有可重复收益、可说明的失效边界，并在同预算强对照下有优势，再扩展正式实验。
- 若深挖否定当前候选，再有针对性地恢复新的广度探索。
