# 0029｜动态聚合与增强对齐顺序强控制

创建：2026-11-11T22:01:54.659661+08:00；作者：Codex  (sqs_A100)；原因：将静态可用信息结论放回动态视频，核验同权重/同流场经典聚合基线。

固定前置平均没有形成独立动态优势。原生开发域上，alpha.1/.5的前置平均均被同系数输出后平均在PSNR/SSIM/时间/edge四项均值支配；不能从R19静态结果直接宣称前置方法成立。下一步做聚合感知训练及初始化控制，仍不把经典平均或scalar gate当创新。

## 控制与完整性

零新训练，R14 native plain双seed4000、同原46条件、同官方teacher半尺度FB。八方法包括raw、前置有限两帧alpha.1/.5、先增强前帧再warp后聚合、先warp输入再增强后聚合及原recursive half01；两reset全报。不用GT flow部署。三个CPU fixture验证仿射交换、平方Jensen差及边界/reset。

1472逻辑行，1072真实指标、400精确alias，逐帧/逐片核查。368次raw/recursive与R14逐帧及逐片指标回放最大差0，首帧像素差0；共同数据/权重/流场无数值漂移。共享368模型序列pass、7660frame forward仅实验计数，不是1472独立视频或单方法部署成本。

## 资源、调研和接续

两成功GPU2/3、峰值2，162源码SHA匹配，379.042进程GPU秒含CPU；没有训练更新。阶段耗时若查看，只含同步GPU forward/stack/clamp和Python，不含teacher/flow/传输/指标，不能当手机或全pipeline；先增强aligned prior需额外模型前向。

调研发现KPN（CVPR2018）明确讨论模型只使用参考帧的局部最优和退火训练；正在核对原文，后续不能将“防止忽略历史”本身称新颖。下一轮保持R14 native全部监督/ROI/合成不变，对齐history每step共享一次、模型/Adam独立：固定pre/post平均，以及可学alpha在0/.5的初始化控制。先确认聚合训练分布与优化因素，再考虑FST统计适配结构。
