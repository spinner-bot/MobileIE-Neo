一、演示目标
------------
按 MobileIE 论文的官方流程，在安卓手机上用 AI Benchmark 跑出真实推理延迟；
效果画面用同一份 TFLite 模型在电脑上生成的对比图展示。

二、手机端操作（约 10 分钟，建议提前做完）
------------------------------------------
1. 安装 AI Benchmark
   - 手机浏览器打开 https://ai-benchmark.com/download
   - 下载 "Direct APK Download"（约 1.98 GB，需预留 5 GB 空间）
   - 允许“安装未知应用”，完成安装；首次打开授予存储权限

2. 放入模型
   - 把本包的 model.tflite 复制到手机内部存储的 Download 目录
   - 路径应为：内部存储/Download/model.tflite
   - 传输方式：USB、微信文件传输助手、adb push 均可
   - adb 示例：adb push model.tflite /sdcard/Download/model.tflite

3. 先跑一次标准测试
   - 打开 AI Benchmark，完整跑一次默认测试
   - 部分版本需要跑完才显示 PRO Mode 入口

4. 加载自定义模型
   - 进入 PRO Mode → Custom Model
   - 选择 Download/model.tflite；若看不到文件，在文件管理器里开启“显示内部存储”
   - 一加 9R 已验证方案：先选 FP16，再选 TFLite GPU Delegate
   - 核对运行表头为 GPU / FP16；切换精度会将后端重置为 CPU，需重新选择
   - 模型文件仍是 FP32，FP16 是 GPU 执行档位；不要选 INT8

5. 验收前复跑并记录
   - 以 GPU / FP16 为主；需要时补充 CPU（4 线程）对照
   - 一加 9R 11 月 12 日参考：GPU FP16 5.76 / 5.95 ms，CPU 86–91 ms
   - GPU 初始化约 450 ms，不计入上述单帧推理延迟；本次以实际读数为准
   - 保存本次截图，并补一段完整操作录屏作为备用
   - 避开 Arm NN（既有测试会崩溃并清空设置）和 INT8（当前模型输入不兼容）

三、现场演示流程（约 3 分钟）
------------------------------
1. 打开 AI Benchmark，展示已加载的 model.tflite
2. 核对 GPU / FP16 后运行，展示单帧推理延迟
3. 如导师需要，再运行 CPU（4 线程）对照
4. 打开“效果对比”文件夹，展示低光增强前后画面
5. 收尾口径：
   “同一份 23 KB 的 TFLite 模型，手机端实测 X ms；
    画质对比由官方推理脚本在同一模型上生成。”

五、常见问题
------------
- 找不到 PRO Mode：先完整跑一次标准测试，确认 App 为 v4 以上（建议 v7）
- 看不到 model.tflite：检查存储权限；文件管理器开启“显示内部存储”
- 模型路径变空：重新选择 Download/model.tflite，核对输入输出
- 运行卡死/闪退：提前排查；现场先展示历史截图/录屏与对比图，说明拍摄日期
- 验收前保留已跑通的 App 与模型配置；避免临场更换运行时或清除 App 数据

六、注意
--------
- AI Benchmark 只输出延迟，不显示增强后的图像，这是 App 本身的限制
- 延迟倒数换算的约 170 次/秒不包含摄像头采集、预处理与显示
- 现场不要依赖网络，APK、模型、录屏、对比图都提前离线准备好
- 手机电量充足，关闭省电模式，避免降频影响数值
