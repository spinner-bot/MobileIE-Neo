微光实验室 · MobileIE 0.2.0 演示版
==================================

安装：adb install -r MobileIE-LightLab-0.2.0.apk，或复制APK到手机打开。
与旧版同签名，保留数据覆盖升级即可；开发调试签名，非商店发布版。
支持ARM64手机/x86_64模拟器，最低声明Android10；本版已验收Android15模拟器。
0.1.2在一加9R已通过；0.2.0仍需同机彩排，不能沿用旧版真机结论。
按此前约定：一加13不安装App，只保留静态对比图备用。

操作（建议2分钟）
-----------------
1. 选择“低光增强”，打开内置样例01，点“开始对比”。
2. 画面上方明确显示“本次任务：低光增强”。
3. “动态对比”并排显示原图↔baseline、原图↔MobileIE；拖任一窗口，两条分界线同步。
4. 切到“静态总览”，同时展示原图、MobileIE、baseline。
5. 切换水下增强/RAW→RGB ISP，分别用内置对应样例处理，重复两种展示。
   切换任务会清除旧结果并准备新样例；未处理前显示“当前任务…待处理”。
6. 低光模式可现场拍照、从系统相册选暗光照片；水下模式也可选RGB图片。
   系统相机返回的是RGB照片，ISP模式不提供拍照入口。
7. 向下滚动保存，Pictures/MobileIE包含4张PNG；Download/MobileIE包含记录JSON。
   ISP额外保存原始.rggb。组合图和记录均标注任务/方法，便于离线备用。

任务与边界
-----------
低光：官方LOL模型，固定Gamma0.5作为baseline，不包含降噪。
水下：官方UIEB权重，固定灰度世界白平衡作为baseline。
上述原图为方向校正、居中3:2取景后600×400输入，并非整张相机原片。
ISP：官方Zurich RAW→RGB权重；固定双线性去马赛克+白平衡+sRGB编码baseline。
仅接收配套448×448 Huawei P20 RGGB .rggb，普通JPG/PNG及任意DNG不能作为RAW。
内置样例来自真实传感器；模型按原代码/4095归一化，四通道输入224×224×4。
“RAW可视化”是10bit强度预览，保留马赛克，不是未经说明的RGB原片。
三种模型都只有一个图像输入，没有可调原生参数，因此没有参数面板。
所有处理在本机离线进行；本App处理单张照片，不提供实时增强取景。
模型和样例出处随包保存在assets/credits.txt及task-asset-sources.json。

与AI Benchmark配合
-------------------
按钮尝试打开已安装的AI Benchmark。进入PRO Mode→Custom Model后手动选择
对应任务的.tflite，不能把低光模型的历史延迟当作水下或ISP结果。
演示包models/包含三份模型和tasks.json。UIE/ISP尚未在真机AI Benchmark测速。
既有一加9R低光GPU FP16约5.8ms，是11月12日历史数据；App显示CPU本次耗时。
微App使用CPU4线程内置算子，桌面CPU1线程；各程序的计时独立。
已知低光模型不应选择INT8或Arm NN，后者历史测试崩溃。切换配置后核对表头。
不自动读取Benchmark跑分，不自动传图；没有安装它也能完整演示效果。

现场异常
---------
取消拍照/选图保留旧结果；文件过大（32MB）或解码失败时换图。
模型失败明确显示“未生成”，仍可查看和保存baseline，不把它当成模型输出。
用合适的内置样例先验流程，随机照片可能超出训练场景而过曝。
投影可展示Python桌面版；保留静态对比图与模拟操作录像作备用。
模拟器合成相机不证明真实暗光画质，也不代表手机速度。
