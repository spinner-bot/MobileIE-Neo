微光实验室 · MobileIE 0.1.1 演示版
==================================

一、安装
--------
将 MobileIE-LightLab-0.1.1.apk 复制到安卓手机，点击并允许本次安装；
也可以通过已授权的 USB 调试连接，在电脑执行：
    adb install -r MobileIE-LightLab-0.1.1.apk

此包为开发调试签名的验收演示版，支持 ARM64 手机及 x86_64 模拟器。
最低声明 Android 10；本次自动化验收在 Android 15 模拟器完成。
一加 9R 的真实拍照、系统相册和处理速度仍需在接机后检查。

二、图片效果演示（建议约 2 分钟）
------------------------------
1. 打开“微光实验室”，点“内置样例”，选择 01 书柜，先熟悉流程。
2. 点“开始对比”，等待本机完成 MobileIE 与 Gamma 处理。
3. 左右拖动分界线，查看同一位置；切换 Gamma 0.5 与三图总览。
4. 点“现场拍照”，在系统相机拍一张暗光照片，确认后返回 App。
5. 检查预览取景范围，再点“开始对比”，展示刚刚拍摄照片的结果。
6. 也可通过“相册选图”处理已有照片。
7. 向下滚动，点“保存对比结果”。图片位于相册 Pictures/MobileIE，
   计算记录位于 Download/MobileIE。

三、讲解口径
------------
“这里用 MobileIE 官方模型在手机本地处理真实照片，和固定 Gamma 调亮
方法对比。三种画面使用同一份 600×400 输入，Gamma 不包含降噪。
接下来用 AI Benchmark 独立展示同一份模型的推理延迟。”

App 中的原图是方向校正、居中裁剪到 3:2 并缩放后的处理输入，
不是整张未经裁剪的手机原片。先确认裁剪范围，再处理。
本 App 为拍照后的单张处理，不是摄像头实时增强取景器。

四、与 AI Benchmark 配合
------------------------
“AI Benchmark ↗”按钮尝试打开已安装的 App。
进入 PRO Mode → Custom Model 后，仍需手动选择原有 model.tflite。
一加 9R 已测的组合：先选 FP16，再选 TFLite GPU Delegate，确认表头。
历史 GPU 单帧 5.76 / 5.95 ms；CPU 86–91 ms。它们是 11 月 12 日历史数据。
微光实验室当前使用 CPU 内置算子，显示自己的本次计时，不沿用这些数字。
不要选择 INT8 或 Arm NN：原有模型未量化，Arm NN 在既有测试中会崩溃。

五、现场异常
------------
- 取消拍照或选图会保留上一次结果。
- 相机不可用时可用相册或内置样例；相机返回空照片时需要重新拍摄。
- 图片超过 32 MB 或无法解码时，换一张 JPG/PNG 图片。
- MobileIE 失败时明确显示未生成；Gamma 仍可看，不能说成模型输出。
- 未安装 AI Benchmark 时仍可完整使用微光实验室。
- 所有图片本地处理；现场准备历史测速截图与离线对比图作备用。

六、验收前检查
--------------
在一加 9R 上完整走一遍：安装 → 样例处理 → 拍照 → 相册 → 对比 → 保存
→ 打开 AI Benchmark → 切回本 App，留存实际截图/录屏与反馈。
模拟器相机使用合成场景，不证明真实暗光画质，也不代表手机处理速度。
