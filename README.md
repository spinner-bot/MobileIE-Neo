## 目录结构

| 目录 | 用途 |
| --- | --- |
| `specs/` | 需求规格与设计说明（项目文档的权威来源） |
| `docs/` | 工程文档：`architecture/` 架构、`api/` 接口、`guides/` 使用指南 |
| `src/` | 源代码 |
| `tests/` | 测试用例 |
| `scripts/` | 开发 / 训练 / 构建脚本 |
| `configs/` | 配置文件 |
| `data/` | 数据：`raw/` 原始数据、`processed/` 处理结果（内容不入库） |
| `notebooks/` | 实验与分析 Notebook |
| `assets/` | 图片等静态资源 |

## 快速开始

```bash
git clone git@github.com:spinner-bot/MobileIE-Neo.git
cd MobileIE-Neo
```
