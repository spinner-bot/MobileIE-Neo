# MobileIE-Neo

面向手机端的轻量图像增强模型研究：在 MobileIE（极轻量实时图像增强 ConvNet）基础上，解决其应用于视频时产生的帧间闪烁问题。

## 当前研究状态

目前处于前期探索，调研、受控训练与多种方法/组合预实验并行，尚未确定最终模型。主线在 `main` 推进，移动演示由独立支线处理。

最新结果见[进展报告0018](docs/进展报告/0018-T-26111118-输入时域化与优化强对照.md)及[4号工作入口](research/4.temporal-consistency/README.md)。冻结特征融合尚未统一超过RGB后处理，双帧首层也未建立独立时域优势；可折叠单帧分支提示优化条件是重要混杂因素。下一步核验学习率强基线与新开发片段。远期论文研究目标持续进行；当前实拍仍为白天ND衰减，自然夜景泛化尚未验证。

新GPU任务必须先检查共享卡的显存、利用率和计算进程，使用同组最多4张空闲卡；本项目提供可审计的启动检查脚本。
