# MobileIE-Neo

面向手机端的轻量图像增强模型研究：在 MobileIE（极轻量实时图像增强 ConvNet）基础上，解决其应用于视频时产生的帧间闪烁问题。

## 当前研究状态

目前处于前期探索。R28/R34/R37具体候选均未通过强传统参考门槛，已冻结其局部扩展；当前优先检验跨域增强映射与时间建模的共同约束，尚未确定最终模型。主线在 `main` 推进，移动演示由独立支线处理。

最新结论见[进展报告0043](docs/进展报告/0043-T-26111204-内部时间算子双种子闭环与路线止损.md)、[论文证据表](research/4.temporal-consistency/report/paper-main-table/README.md)及[4号入口](research/4.temporal-consistency/README.md)。R28收口训练48000新更新、4416行共同CUDA主评价及R30双seed312行外部CPU评价均已完成。真实历史和单帧current均未通过质量—时序筛查，不再扩大相似算子网格；主表已保留实测负结果及同权重强post。真实手机输入已准备，方法质量、手机延迟与完整独立基准仍缺。

最新收口见[0048](docs/进展报告/0048-T-26111207-动态骨干双种子闭环与公开方法迁移收口.md)：R34六模型24000更新、120行最终共同CPU质量与42次CPU成本均正常结束，双seed未过强post门槛，该设计局部扩展已冻结。R35公开FastDVDnet固定权重迁移36行完成，训练来源含三开发视频，结果属于开发迁移，不是未见泛化。[完整决策](research/4.temporal-consistency/docs/exploration-r34-decision.md)保留质量与部署取舍；手机实测及有效新方法仍待完成。
