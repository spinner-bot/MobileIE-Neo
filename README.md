# MobileIE-Neo

面向手机端的轻量图像增强模型研究：在 MobileIE（极轻量实时图像增强 ConvNet）基础上，解决其应用于视频时产生的帧间闪烁问题。

## 当前研究状态

目前处于前期探索，调研、受控训练与多种方法/组合预实验并行，尚未确定最终模型。主线在 `main` 推进，移动演示由独立支线处理。

最新结果见[进展报告0020](docs/进展报告/0020-T-26111118-原生尺度与匹配区域诊断.md)及[4号工作入口](research/4.temporal-consistency/README.md)。强单帧优化在原生裁剪仍有效，粗输入平滑则牺牲画质换取更低时间误差。R11已完成6000步强优化训练，正在比较原始历史、运动对齐历史与同容量空间对照。论文目标持续进行，尚未确定新方法；ND开发数据不代表自然夜景或最终测试。

新GPU任务必须先检查共享卡的显存、利用率和计算进程，使用同组最多4张空闲卡；本项目提供可审计的启动检查脚本。
