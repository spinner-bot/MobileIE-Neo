# MobileIE-Neo

面向手机端的轻量图像增强模型研究：在 MobileIE（极轻量实时图像增强 ConvNet）基础上，解决其应用于视频时产生的帧间闪烁问题。

## 当前研究状态

目前处于前期探索，调研、受控训练与多种方法/组合预实验并行，尚未确定最终模型。主线在 `main` 推进，移动演示由独立支线处理。

最新结果见[进展报告0015](docs/进展报告/0015-T-26111116-因果骨干与同容量反证.md)及[4号工作入口](research/4.temporal-consistency/README.md)。20次同流训练表明，本轮低分辨率历史分支收益主要可由同位单帧改造复现，尚未建立独立视频结构贡献。远期论文研究目标持续进行，接下来分解FST噪声传播机制；当前实拍数据来自白天ND衰减，尚不能证明自然夜景泛化。

新GPU任务必须先检查共享卡的显存、利用率和计算进程，使用同组最多4张空闲卡；本项目提供可审计的启动检查脚本。
